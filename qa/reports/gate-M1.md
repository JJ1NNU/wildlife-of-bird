## 2. 시뮬레이션 무오류 — 통과
공식 명령으로 실행(리허설과 같은 시드). 오류 판 = `qa/test-strategy.md` 2장 불변식 1~6 중 하나라도 깨진 판.

```
npm run sim -- --bot qa/bots/random.ts --species parus-minor --runs 1000 --seed-prefix gate-m1-rnd --out rnd.jsonl
npm run sim -- --bot qa/bots/avg.ts    --species parus-minor --runs 1000 --seed-prefix gate-m1-avg --out avg.jsonl
```

| 봇 | 판 | 오류 | 게임 오버 못 감 | 평균 생존(년) ±95% | 중앙 | 10년 초과 | 최장 | 번식/판 |
|---|---|---|---|---|---|---|---|---|
| 무작위 `random@0.2.0` | 1,000 | **0** | 0 | 0.354 ±0.008 | 0.33 | 0 | 1.21 | 0.01 |
| 평균 `avg@1.0.0` | 1,000 | **0** | 0 | 4.765 ±0.217 | 4.25 | 100 | 21.08 | 4.04 |

- 생존 연수 = `year − 1 + (period − 1)/24`(게임 오버 시점).
- 모든 판이 상한 100년 안에 게임 오버로 끝났다(불변식 5).
- 참고(관문 조건 아님): 평균 봇 수치는 리허설(main `0d2dc2f`, 4.694년·번식 3.98)과 비슷하다. 밸런스 판단은 M2 관문에서 한다.

## 3. 결정론 — 통과
위 기록 파일로 공식 리플레이 명령을 실행. 같은 시드로 `newRun` 후 기록한 선택을 다시 `act` → 최종 `serialize` 결과를 원래와 비교. `--resume-at k`는 k번째 선택 뒤 `serialize` → `deserialize` 후 나머지를 이어 재생(저장/불러오기 왕복).

```
npm run sim -- replay rnd.jsonl                 # 1,000판
npm run sim -- replay rnd.jsonl --resume-at 5   # 1,000판, 왕복
npm run sim -- replay avg.jsonl                 # 1,000판
npm run sim -- replay avg.jsonl --resume-at 60  # 1,000판, 왕복
```

| 기록 | 리플레이 | 저장/불러오기 왕복 |
|---|---|---|
| 무작위 1,000판 | 다름 **0** | resume 5 — 다름 **0** |
| 평균 1,000판 | 다름 **0** | resume 60 — 다름 **0** |

기준(200판 모두 일치)보다 많은 판을 확인했다.
