## 결론
- **무오류 ✅** — 두 봇 각 1,000판, 오류 0판, 전부 게임 오버로 끝남(상한 도달 0).
- **결정론 ✅** — 리플레이 1,000판 다름 0(평균 봇), 저장/불러오기 왕복(`--resume-at 3`) 1,000판 다름 0(무작위 봇).
- **밸런스 ❌ — 측정 전제 미달.** 어떤 봇도 첫 겨울을 못 넘긴다. #143(겨울 에너지 수지 음수)을 평균 봇으로 따로 확인했다. 런 길이·총 번식 수 목표는 #143 반영 뒤 M1-02에서 잰다.

- 평균 봇은 1,000판 모든 결정에서 `action.forage`를 골랐다 — 에너지가 상한의 75%를 넘는 순간이 없어 훈련 규칙이 한 번도 안 열렸고, 먹이 찾기가 늘 가장 덜 잃는 선택이다. 그래도 겨울 6단계 동안 에너지가 계속 준다.
- 런 시작 개체의 현재값 = 잠재력(엔진 잠정, #143)이라 훈련의 `statGains`가 비어 있다. 이대로면 평균 봇은 훈련을 고르지 않는다.
- 성능: 지난 측정(자리표시 엔진, 판당 0.86초)보다 훨씬 빠르지만 판이 6~13결정으로 짧아 비교가 안 된다. 판이 길어지면 다시 잰다.

## 평균 봇 v0 규칙 (`qa/bots/avg.ts`)
1. 에너지 ≥ 상한의 75%면 능력치가 가장 많이 오르는 훈련(훈련 뒤 에너지 ≥ 상한의 50%일 때만).
2. 아니면 `예상 에너지 변화 가운데 − 100 × 사망 위험`이 가장 큰 선택.
번식 선택(산란 수·짝 등)은 04-breeding 구현 뒤 v1에서 규칙을 따로 둔다.

## 재현
```
npm run sim -- --bot qa/bots/random.ts --species parus-minor --runs 1000 --seed-prefix qa-m1 --out random.jsonl
npm run sim -- --bot qa/bots/avg.ts    --species parus-minor --runs 1000 --seed-prefix qa-m1 --out avg.jsonl
npm run sim -- replay avg.jsonl
npm run sim -- replay random.jsonl --resume-at 3
```
