# 출시 체크리스트

> 관리: QA·밸런스. 상태: **v1.1** (#20 — `docs/studio/02-roadmap.md` 6장 관문 판정 기준에 맞춤, D-017).
> **M6 베타 관문 = 이 목록 전부 통과**(02-roadmap 6장 M6). 예외는 대표가 **항목 번호를 지정해** 승인한다. 최종 출시는 대표가 결정한다.
> 각 항목은 **확인 방법**과 **근거**(리포트·이슈·PR 링크)를 남겨야 통과다. 판정 때 이 파일을 복사해 `qa/reports/gate-M6.md`에 결과를 채운다.
> 02-roadmap 6장과 이 문서가 다르면 6장이 우선한다(01-collaboration 13장). 다른 점을 발견하면 QA가 이 문서를 맞춘다.

## 0. 공통 기준 (02-roadmap 6장 머리말과 같음)

- 지표 번호(M-xx)와 계산법: `qa/metrics.md`. **G** = 종 간 차이 = (종별 값의 최대 / 최소) − 1.
- 밸런스 표본: 종·봇마다 **N = 5,000판**, 95% 신뢰구간 반폭 ≤ 평균의 2.5%. 못 미치면 그 항목은 "판정 보류"이고 N을 늘려 다시 잰다.
- 허용 범위: 종 파일 `data/balance/species/<종>.json`의 `targets`(목표값)와 `targets.tolerance`(현재 0.10, 디자인 #35). 아래 표의 구간은 tolerance 0.10일 때의 값이며, 데이터가 바뀌면 데이터가 우선한다.
- 버그 집계: 판정 시점에 **열려 있는** `type:bug` 이슈를 `sev:S1`·`sev:S2` 라벨로 센다(부서·마일스톤 무관).
- 4종 = 박새 · 꼬마물떼새 · 저어새 · 두루미.

## 2. 밸런스 (`qa/metrics.md`, 0장 공통 기준)

| # | 항목 | 재는 법 | 통과 |
|---|---|---|---|
| B1 | 평균 봇 기대 총 번식 수 | M-01 (4종) → M-03 | 4종 모두 [3.6, 4.4], G ≤ 0.10 |
| B2 | 숙련 봇 공정성 | M-01 · M-02 → M-03 (4종) | 평균과 상위 10% 모두 G ≤ 0.10 |
| B3 | 평균 봇 평균 런 길이 | M-04 (4종) | 기획서 4.5 목표 ±10% — 박새 [4.05, 4.95] / 꼬마물떼새 [4.95, 6.05] / 저어새 [6.75, 8.25] / 두루미 [7.65, 9.35], 모두 10년 이하 |
| B4 | 무작위 봇 · 숙련 봇 런 길이 | M-04 (4종) | 무작위 봇 평균 1~3년, 숙련 봇 평균 20년 이상 |
| B5 | 지배 전략 없음 | M-12 (4종, 고정 전략 목록은 `metrics.md`) | 실패 0, 판정 보류 0 |
| B6 | 1년 결정 수 | M-11 (4종) — 결정 1회 = 고를 수 있는 선택이 2개 이상인 `act` 호출 1회(`docs/design/specs/00-core-loop.md` 5.1) | 4종 모두 평균 [60, 90] |

B1·B3·B5·B6은 M2(박새)·M4(두루미)·M5(4종) 관문에서 이미 잰 항목이다. M6에서는 **베타 빌드 커밋으로 다시 잰다**(그 사이 수치·콘텐츠가 바뀌었기 때문). B4는 로드맵 관문에 M2(박새)만 있어 4종 확인을 여기서 한다.

## 8. 배포 (베타 빌드 기준)

M6 판정은 **베타 주소**로 한다. 프로덕션 배포·버전 `1.0.0` 표시·배포 후 스모크는 M7 관문(02-roadmap 6장 M7)에서 프로덕션 주소로 다시 확인한다.

| # | 항목 | 확인 방법 |
|---|---|---|
| R0 | CI: main 최신 커밋에서 `ci.yml`(타입체크 · 린트 · 테스트 · 데이터 검증)과 `deploy.yml`(웹 빌드 `npm run build -w @wb/web`) 모두 성공 — 02-roadmap 6장 M0와 같은 기준(D-017, ADR-001에 패키지 빌드 없음) | `gh run list --branch main --workflow ci.yml --limit 1` · `--workflow deploy.yml --limit 1` 결과 |
| R1 | 베타 주소가 대표 폰에서 열리고 PWA로 설치됨 | 대표 확인 댓글 |
| R2 | 화면의 버전 표시 = `version.json`의 `gameVersion` | 탐색 테스트 |
| R3 | 배포 후 스모크(e2e 1회) 통과 | CI 또는 수동 실행 기록 |
| R4 | 피드백 창구가 준비됨 | PM 이슈 링크 |
