# 출시 체크리스트

> 관리: QA·밸런스. 상태: **v0** (M0, #19). M6 베타 관문 = 이 목록 전부 통과(로드맵 1장). 최종 출시는 대표가 결정한다.
> 각 항목은 **확인 방법**과 **근거**(리포트·이슈·PR 링크)를 남겨야 통과다. 판정 때 이 파일을 복사해 `qa/reports/gate-M6.md`에 결과를 채운다.
> v0는 틀이다. 숫자 기준이 "(미정)"인 항목은 해당 부서의 결정(ADR·명세)이 나오면 채운다.

---

## 1. 기능

| # | 항목 | 확인 방법 | 담당 근거 |
|---|---|---|---|
| F1 | 4종 모두 새 게임 → 번식 → 계승 → 게임 오버까지 진행된다 | e2e 스모크(종마다) + 탐색 테스트 | qa |
| F2 | 저장/이어 하기: 아무 단계에서 앱을 닫고 다시 열면 같은 자리에서 이어진다 | e2e 스모크(새로고침), 리플레이 검사 저장 왕복 | qa |
| F3 | 시뮬레이션 무오류: 4종 × 무작위·평균 봇 각 1,000판, 오류 0 | `qa/reports/` 시뮬레이션 리포트 | qa |
| F4 | 결정론 리플레이 검사 통과(K=200) | 리포트 | qa |
| F5 | 리더보드 제출 · 조회, 주간 시드(같은 주 같은 시드) | e2e 또는 탐색 테스트 기록 | client |
| F6 | 열린 S1 버그 0, S2 버그 0(또는 대표가 예외로 승인한 목록) | 이슈 검색 결과 링크 | qa |

## 2. 밸런스 (`qa/metrics.md`)

| # | 항목 | 기준 |
|---|---|---|
| B1 | 평균 봇 기대 총 번식 수 | 4종 모두 [3.6, 4.4], 종 간 차이 G ≤ 0.10 |
| B2 | 숙련 봇 공정성 | 평균과 상위 10% 모두 G ≤ 0.10 |
| B3 | 평균 런 길이 | 종별 목표 범위 안(허용 범위 잠정(#20)), 모두 10년 이하 |
| B4 | 무작위 봇 · 숙련 봇 | 무작위 평균 런 1~3년, 숙련 평균 런 20년 이상 |
| B5 | 지배 전략 없음 | M-12 실패 0 |
| B6 | 1년 결정 수 | 4종 모두 평균 [60, 90] |

## 3. 생태 정확성

| # | 항목 | 확인 방법 |
|---|---|---|
| E1 | `factCheck: "needs-review"`인 데이터 0개 — 또는 출시 빌드에서 제외됨 | `data/**` 검색 결과(명령과 결과 수를 근거에 적음) |
| E2 | 기획서 12장 생태 오류 체크리스트 항목이 게임에 없음 | 콘텐츠 최종 검수 결과 + QA 탐색 테스트 |
| E3 | 새·포식자 그림의 생태 정확성 검토 완료 | art 에셋 PR의 content 승인 |
