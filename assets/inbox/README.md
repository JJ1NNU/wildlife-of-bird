# 이미지 투입함 (대표 → 아트·UX)

대표님이 이미지 생성 도구로 만든 그림을 넣는 곳입니다.

1. 아트·UX의 `[art→대표] 이미지 생성 배치 NN` 이슈를 엽니다.
2. 이슈에 적힌 파일명 그대로 `assets/inbox/batch-NN/` 폴더에 올립니다.
   - 형식: WebP 또는 JPG, 긴 변 1024px 이하, 에셋당 후보 최대 2장
   - 예) `assets/inbox/batch-01/bird.parus-minor.adult-m.breeding.perch__1.webp`
   - git으로 푸시하거나, GitHub 웹에서 이 폴더를 열고 "Add file → Upload files"로 main에 바로 올리셔도 됩니다(이 폴더만 예외).
   - 이슈 첨부는 쓰지 마세요. 에이전트가 내려받지 못할 수 있습니다.
3. 이슈에 `완료 — 사용 도구: ○○` 댓글을 답니다.

아트·UX가 고르고 다듬어 `assets/`의 정식 위치로 옮긴 뒤, 처리한 원본은 정리합니다.
