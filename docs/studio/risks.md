# 위험 관리

> 관리: PM. 라운드 끝 근무마다 다시 본다. 새 위험은 발견한 부서가 `dept:pm` 이슈로 알린다.
> 가능성·영향: 높음 / 중간 / 낮음. **대응**은 지금 당장 할 수 있는 행동으로 적는다.

## 현재 위험 (v1 — 2026-10-03, M0 시작 시점)

| ID | 위험 | 가능성 | 영향 | 대응 | 담당 |
|---|---|---|---|---|---|

## 기록 방법
- 새 위험: 표에 `R-0xx` 추가.
- 해소: "해소된 위험"으로 옮기고 해소된 날짜와 근거(이슈·PR)를 적는다.
- 터진 위험: 대응이 실패했으면 대응 칸을 고치고 대표 보고의 "막힘"에 올린다.
