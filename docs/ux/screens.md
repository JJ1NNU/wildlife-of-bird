# 화면 목록 (1.0까지)

> 소유: 아트·UX. 화면 **흐름**을 바꾸는 것은 L2(디자인·클라이언트와 합의) — `type:decision` 이슈로.
> 게임디자인의 `specs/screens.md`(M1)는 **화면마다 어떤 정보·수치가 필요한가**를 정한다. 이 문서는 **화면이 몇 개이고 어떻게 이어지는가**를 정한다. 둘이 어긋나면 `specs/screens.md`가 우선이다(01-collaboration 13장).

## 1. 세로 한 손 기준 (모든 화면 공통)

- 대상 폭 **360px ~ 430px**, 높이 **640px ~ 932px**. 가장 좁고 낮은 **360×640에서 설계하고**, 넓어지면 여백이 늘어나게 둔다.
- **가로 스크롤 없음.** 목록이 길면 그 목록만 세로로 스크롤한다. 가로 스와이프 목록은 쓰지 않는다(새끼 카드, 장소 카드 모두).
- 터치 영역 **44×44px 이상**, 사이 간격 8px 이상. 주 행동 버튼은 화면 아래쪽 1/3(엄지 범위)에 둔다.
- 글자 대비 **WCAG AA**. 그림 위 글자는 단색 띠나 반투명 판 위에 올린다.
- **확률·예상치를 보여준다**(gdd 3장 원칙 5). 되돌릴 수 없는 선택을 포함한 모든 행동 버튼에는 **예상 결과 + 위험%** 자리가 있다. 아래 표의 "확률 자리" 열이 그 자리다.

**저충실도에서 바뀐 것**
- **결정 영역 = 높이 550**(클라이언트 #53): 상태 바부터 결정 버튼까지 550 안. 그 아래(이야기 피드·설명)만 스크롤. 그림은 ≤550에서 120, 그 이상 172.
- **#38 결정 A**: 장소 줄은 버튼이 아니라 그림 아래 반투명 판의 **정보**. 행동 목록의 `옮기기 ▾`를 펼치면 목적지 카드(최대 4) — 행동 줄과 같은 자(에너지 · 위험% · 먹이·경쟁 등급).
- 행동 줄마다 **에너지 변화 · 위험% · 예상 성장** 셋(#52). 위험은 색 + 아이콘 + 숫자 + 낱말(낮음·보통·높음, `display.riskBands`).
- **숫자 표기**(`01-formulas` 7.0, #648): 에너지·깃털은 어디서나 소수 첫째(`64.0 / 64.0` · `−1.5` · `78.5`), 변화는 표시값끼리의 차. 스탯·잠재력·상승량은 정수(버림), 상승이 `+0`이어도 그 스탯을 보인다(7.0 예시 넷째 줄 — 훈련 카드가 무엇을 올리는지 보여야 함, #667). 상태 바 둘째 줄 최악 `에너지 100.0 / 100.0 · 깃털 100.0`도 360 폭에 26px 남음(10/23 측정).
- 짝 지시 수락률은 **등급만**(숫자 없음, `01-formulas` 7.4) — 저충실도의 %를 지웠다. 번식 패널 탭 38 → **44px**.
- 굶주림 경고는 배너가 아니라 **상태 바 전체**(경고 바탕 + "굶주림" 낱말) — 결정 영역 높이를 쓰지 않으려고.
- 겹침(S-12·S-13)은 상태 바를 덮지 않는다 — 에너지를 보며 고르게.
- 번식 국면의 S-10은 그림 아래 판이 **둥지 띠**(국면·단계·알/새끼·둥지 손실%·건 지시)가 된다. 짝 지시는 **둥지 국면 첫 단계에만**, `00-core-loop` 3장 순서대로 행동 다음에 번식 패널에서(`04-breeding` 3.1).

## 6. 한눈 화면 v2 (#611 — 대표 지시 2026-10-21)

> 대표: "내 패에는 가진 것만, 폰 한 화면에 한눈에, 사용자 편의 최대, 확장성." → **판 화면을 스크롤 없는 한 장(360×640)**으로 다시 짠다. 와이어: [07-one-screen.html](wireframes/mid/07-one-screen.html). 이 장이 4.1의 "결정 영역 550 + 아래 피드 스크롤"과 06(칸 고르고 → 가로 패 넘김)보다 우선한다.
> 1차: **S-10 카드 턴**과 공통 틀(영역·시트·메뉴) — 와이어 07. 2차: 이벤트·계절 방침·번식·계승·게임 오버를 같은 틀에 옮긴 **관문 시트** — 와이어 [08-gate-sheets.html](wireframes/mid/08-gate-sheets.html), 6.6.

### 6.1 원칙

1. **가진 것만 그린다.** 패에 없는 카드·못 가는 곳·아직 없는 기능은 화면에 자리를 만들지 않는다. 다 쓴 카드는 패에서 빠진다.
2. **한 화면, 스크롤 없음.** 360×640에서 판 화면 전체가 들어간다. 넘칠 때 줄어드는 곳은 그림 띠(C) 하나뿐.
3. **한 번 누르면 한 가지.** 카드를 누르면 다음 빈 칸에 들어간다(칸을 먼저 고르지 않는다). 자세한 것은 따로 펼치지 않고 정보 줄(G)에 저절로 나온다.
4. **엄지 아래.** 고르는 것(패·늘 있는 카드)과 실행 버튼은 화면 아래 절반. 위쪽은 보는 것(상태·장소·그림·칸).
5. **판 밖으로 가는 길은 ≡ 하나.** 도감·설정·지난 일·개체 상세는 메뉴 시트로. 지도만 장소 줄에 남긴다(옮기기 판단에 쓰므로).

### 6.2 영역 (위 → 아래, 360×640)

| 영역 | 높이 | 내용 | 나중에 붙일 자리 |
|---|---|---|---|
| A 상태 바 | 56 고정 | 시기·단계 n/24 · 총 번식 / 에너지 막대·숫자 · 깃털 · 오른쪽 ≡(48×56). 굶주림이면 바 전체 경고 바탕(4.1 그대로) | 상태 아이콘(부상 등)은 둘째 줄 끝 |
| B 장소 줄 | 44 고정 | 장소 이름 · 먹이·경쟁 등급 · 오른쪽 [지도](44 이상) | 환경 카드 한 줄 요약 |
| C 그림 띠 | **남는 높이, 0~120** | 새 그림 · 개체 칩(누르면 개체 상세) · 번식기엔 둥지 띠(4.1) | 다른 종 그림, 계절 배경 |
| D 칸 줄 | 84 고정 | 머리 줄(루틴 k/n칸 · 예산 "18 중 10" + 막대) · 칸 n개(52 높이). 칸 = 아이콘 + 그 칸 뒤 예상 에너지(배고픔 구간 아래면 `ochre-strong`). 다음 빈 칸 = 2px `sage-strong` 점선 | 겹치기·순서 보너스 표시(칸 안 작은 표) |
| E 패 | 20 + 줄 수 × 60 | **가진 카드만** 3열 격자(ui-kit 3.1). 머리 줄 "패 k장" | 스티커(카드 모서리) · 남겨 두기 표시 |
| F 늘 있는 카드 | 52 고정 | 옮기기 ▾ · 채식(기본) · 쉬기 — 패와 다른 모양(보조 버튼 모양) | — |
| G 정보 줄 | 52 고정 | 마지막에 넣은 카드나 누른 칸의 **전체 효과**(성장·에너지 → 칸 뒤 값·위험 띠). 칸을 눌렀으면 오른쪽에 [빼기]. 못 쓰는 카드를 눌렀으면 이유 한 줄(왼쪽 선 `danger`). 아무것도 안 눌렀으면 사용법 한 줄 | 갈래 확률(대성공·성공·아쉬움) |
| H 행동 바 | 64 고정 | [되돌리기](96) · [실행 · 빈 칸은 쉬기](주 버튼). 아래 여백 + safe-area | — |

- 고정 합 = 56+44+84+52+52+64 = **352**. 패 2줄이면 E = 140 → C = 120(상한, 남는 28은 아래 여백). 3줄(7~9종) → C ≈ 88. 4줄(10~12종) → C ≈ 28 — 그림은 숨기고 개체 칩만.
- 그보다 많으면(드묾) **E만** 세로 스크롤(칸·버튼은 제자리). 화면 전체 스크롤은 없다.
- 키가 크면(> 640) C가 120에서 멈추고 남는 높이는 E와 F 사이 여백으로. 폭이 넓어도(≤ 430) 3열 그대로, 카드만 넓어진다.

### 6.3 조작

| 하는 것 | 결과 |
|---|---|
| 패 카드 누름 | 다음 빈 칸에 들어감 · 장수 −1(0이면 패에서 빠지고 격자는 앞으로 당김) · G에 그 카드 자세히 |
| 못 쓰는 카드 누름 | 칸에 안 들어감 · G에 이유 한 줄(엔진 `disabled.reason` 글) |
| 늘 있는 카드 누름 | 채식(기본)·쉬기 = 다음 빈 칸에. 옮기기 = 아래 시트(목적지 ≤ 4, `.opt` 줄) → 고르면 다음 빈 칸에 |
| 채운 칸 누름 | 그 칸 선택(`.sel`) · G에 그 칸 자세히 + [빼기]. 빼면 카드는 패로 돌아가고 칸은 빈 칸으로(뒤 칸을 당기지 않음) — 순서 바꾸기 = 빼고 다시 넣기 |
| 되돌리기 | 마지막으로 넣은 칸 하나 빼기 |
| 실행 | 빈 칸은 쉬기로 실행(12-card-turn 2.4). 칸별 결과는 시트(S-12)로 |

- 다음 단계의 칸은 **비어서 시작**한다(지난 단계 루틴을 미리 채우지 않음 — 패가 단계마다 달라 미리 채운 칸이 패에 없는 카드가 된다).

### 6.4 판 안의 다른 화면 — 같은 틀의 아래 시트

- S-12 판정 결과 · S-13 이벤트 · S-14 계절 방침 · 옮기기 · 메뉴 · 번식 패널 · S-24 계승 결정은 모두 **아래에서 올라오는 시트**. A(상태 바)는 덮지 않고, 나머지는 `ink` 55%로 어둡게(ui-kit 1장 겹침 시트).
- 시트 높이는 내용만큼, 최대 640 − 56 = 584. 넘치면 **시트 안 목록만** 스크롤하고 시트의 주 버튼은 시트 아래에 고정.
- 시트 안 선택지는 **줄**(`.choice` · `.opt`)이다. 패 카드 모양(ui-kit 3.1, 52px)은 판 화면 패에만 — 관문 선택지는 문장·설명·확률이 여러 줄이라 작은 카드에 안 들어간다(6.6).

### 6.5 판 밖 (메뉴 ≡)

- 메뉴 시트 줄: **지난 일**(지금의 피드) · **개체 상세**(S-15) · **도감** · **설정**(도움말·기록 내보내기·판 지우기). 가계도는 게임 오버·타이틀에만(판 중엔 지난 판이라 의미가 적다).
- 개발용 "1년 빨리 감기"는 설정 맨 아래로(알파 빌드에서만).
- 새 기능(리더보드·업적 등)은 메뉴 줄 하나 또는 타이틀·게임 오버 버튼 하나로 붙인다. 판 화면 영역(6.2)은 늘리지 않는다.

### 6.6 관문 시트 (2차 — 와이어 08)

판 안에서 카드 턴이 아닌 결정(엔진 `view.gate`: 이벤트 · 계절 방침 · 짝 후보 · 둥지 자리 · 알 수 · 짝 지시 · 육아 방침 · 2차 번식 · 계승)은 **모두 같은 시트 하나**로 그린다. 와이어: [08-gate-sheets.html](wireframes/mid/08-gate-sheets.html).

| 부분 | 규칙 |
|---|---|
| 자리 | 상태 바(A) 아래 8px부터, 높이는 내용만큼 · 최대 576(= 640 − 56 − 8). 판 화면은 `ink` 55%로 어둡게 |
| 머리 | 제목 1줄 + 설명 1~2줄(`small`, `ink-muted`) — 이벤트 본문은 줄 제한 없음(최장 100자 ≈ 5줄, 이야기 글은 자르지 않는다). 이벤트만 위에 그림 96 — 넘치면 **그림이 먼저 0까지 접힘** |
| 목록 | 선택지 줄. 이벤트·계절 방침 = `.choice`(이름 · 설명 · 효과/판정 줄), 번식 관문 = `.opt`(이름 · 한 줄 · 오른쪽 값), 계승 = 새끼 줄(사진 40) + 잔류 줄. 넘치면 **목록만** 스크롤 |
| 주 버튼 | 시트 맨 아래 고정, 1개. 안 고르면 `gate.<kind>.none` 글·비활성, 고르면 `gate.<kind>.go`(고른 이름이 들어감) |
| 닫기 | 없음. 골라야 진행(#53-1) — 바깥 누르기·뒤로 무시 |
| 확인 단계 | 계승 확인처럼 한 번 더 묻는 것은 **같은 시트의 내용을 바꾼다**(시트 두 장 겹치지 않음). 왼쪽 [◂ 다시 고르기] |

- 계절 방침: 줄 하나에 이름·설명·다음 단계 예상(에너지·위험 띠)을 다 넣는다 — 지금 구현의 "패 카드 + 고른 카드 설명은 아래"를 대체. 고른 방침은 계절 내내 장소 줄(B)에 한 낱말로 남긴다.
- 육아 방침(항목 × 값)은 항목마다 한 줄 + 오른쪽 값 버튼 묶음(지금 구현 그대로).
- 계승 새끼 줄 = 사진 · 이름 · 1년 생존 · 가장 강한 잠재력 범위 1개. 나머지(은수저·첫 겨울 배율·잠재력 전부)는 고른 줄만 아래로 펼친다.
- 번식기 판 화면: 그림 띠(C) 아래에 **둥지 띠 28**(국면 · 알/새끼 수 · 둥지 위험%)을 겹친다. 이때 C는 28 밑으로 줄이지 않는다 — 그림만 숨고 둥지 띠는 남으며, 모자라는 높이는 패(E) 스크롤로.
- 판정 결과(S-12)도 같은 시트: 목록 = 칸별 결과 줄, 주 버튼 = [계속].
- **게임 오버(S-30)는 시트가 아니다.** 판이 끝났으므로 상태 바·≡ 대신 머리 줄(56), 그림(160, 먼저 접힘) · 점수 · 사망 원인 줄 · 아래 버튼 [가계도] [지난 일] / [플레이 기록 저장](기록 있을 때만, 전체 폭 보조 — #641) / [새 가문 시작]. 공유(M6)는 그때 첫 줄에 하나 더한다.
