# 화면 목록 (1.0까지)

> 소유: 아트·UX. 화면 **흐름**을 바꾸는 것은 L2(디자인·클라이언트와 합의) — `type:decision` 이슈로.
> 게임디자인의 `specs/screens.md`(M1)는 **화면마다 어떤 정보·수치가 필요한가**를 정한다. 이 문서는 **화면이 몇 개이고 어떻게 이어지는가**를 정한다. 둘이 어긋나면 `specs/screens.md`가 우선이다(01-collaboration 13장).

## 1. 세로 한 손 기준 (모든 화면 공통)

- 대상 폭 **360px ~ 430px**, 높이 **640px ~ 932px**. 가장 좁고 낮은 **360×640에서 설계하고**, 넓어지면 여백이 늘어나게 둔다.
- **가로 스크롤 없음.** 목록이 길면 그 목록만 세로로 스크롤한다. 가로 스와이프 목록은 쓰지 않는다(새끼 카드, 장소 카드 모두).
- 터치 영역 **44×44px 이상**, 사이 간격 8px 이상. 주 행동 버튼은 화면 아래쪽 1/3(엄지 범위)에 둔다.
- 글자 대비 **WCAG AA**. 그림 위 글자는 단색 띠나 반투명 판 위에 올린다.
- **확률·예상치를 보여준다**(gdd 3장 원칙 5). 되돌릴 수 없는 선택을 포함한 모든 행동 버튼에는 **예상 결과 + 위험%** 자리가 있다. 아래 표의 "확률 자리" 열이 그 자리다.

## 3. 흐름

```
S-01 ─▶ S-02 ─▶ S-03 ─┐
                       ▼
        ┌──────────▶ S-10 메인 턴 ◀────────────┐
        │             │  │  │                  │
        │        S-11 지도 │  └─▶ S-15 개체 상세 ┤
        │             │  └─▶ S-13 이벤트 ───────┤
        │             ▼                         │
        │        S-12 판정 결과 ─────────────────┘
        │             │
        │        (번식기)  (철새 이동기)
        │             ▼         ▼
        │   S-20 ─▶ S-21·S-22·S-23      S-25 이동
        │                 │                 │
        │                 ▼                 │
        │           S-24 독립·계승 ─────────┘
        │          (총 번식 +1 확정)
        │           계승 / 잔류
        └─────────────┘
                      │  개체 사망
                      ▼
            S-30 게임 오버 ─▶ S-31 가계도 · S-32 리더보드 · S-33 도감 · S-34 칭호
```

- **S-10이 집이다.** 턴 안의 모든 화면은 S-10으로 돌아온다. S-12·S-13은 화면을 갈아 끼우지 않고 S-10 위에 겹쳐 뜬다 — 세로 모바일에서 화면 전환이 잦으면 "지금 어디인지"를 잃는다.
- 되돌릴 수 없는 선택은 **S-24의 계승**뿐이다. 여기서만 확인을 한 번 더 받는다.
- 매 단계 자동 저장(gdd 4.2) — 상태 바에 표시만 하고 저장 버튼은 두지 않는다.

## 4. 저충실도 와이어프레임

`wireframes/`에 SVG 5장. 360×640 기준으로 그렸고, **headless Chrome으로 렌더해 글자 겹침과 세로 넘침이 없는 것을 확인했다.**

| 파일 | 화면 |
|---|---|
| [01-main-turn.svg](wireframes/01-main-turn.svg) | S-10 메인 턴 |
| [02-event.svg](wireframes/02-event.svg) | S-13 이벤트 카드 |
| [03-breeding.svg](wireframes/03-breeding.svg) | S-21·22·23 번식 패널 |
| [04-inherit.svg](wireframes/04-inherit.svg) | S-24 독립·계승 결정 |
| [05-game-over.svg](wireframes/05-game-over.svg) | S-30 게임 오버·생애 기록 |

**범례** — 각 SVG 위쪽에도 적혀 있다.

| 표시 | 뜻 |
|---|---|
| 점선 주황 테두리 | 44px 이상 터치 영역 |
| 주황 글자 | **확률·예상치 자리** |
| 점선 회색 상자 | 그림 자리 (에셋 ID 표기) |
| 진한 회색 채움 | 주 행동(화면당 1개) |

와이어프레임 안의 숫자·문구는 **자리를 보여 주려고 넣은 예시**다. 실제 수치는 디자인의 `data/balance/`, 글은 콘텐츠가 쓴다.
