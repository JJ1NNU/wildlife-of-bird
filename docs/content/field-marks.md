# 야외 식별 특징표

> 관리: 생태·콘텐츠. 그림(실루엣·생성 이미지)이 생태적으로 맞는지 판단하는 기준이다(D-006).
> 아트는 이미지 생성 프롬프트와 후처리 검수에, 콘텐츠는 그림 생태 검토(거부권, `content.md` 11장)에 쓴다.
> 출처 ID는 `sources.md`. **✔** = 출처로 확인, **?** = 출처가 약하거나 없음 — 그림에서 강조하지 말고 콘텐츠에 물을 것.

## 0. 쓰는 법

- 그림 검토는 **1장 박새부터**. 각 종의 "틀리기 쉬운 것" 표가 거부 기준이다.
- "?" 항목은 그리지 말라는 뜻이 아니다. 그 특징을 **눈에 띄게 과장하지 말라**는 뜻이다.
- 나이·계절이 다른 그림(어린 새, 비번식깃)은 파일 이름이나 에셋 목록에 어느 깃인지 적는다 — 검토할 때 기준이 달라진다.

## 1. 박새 (*Parus minor*) — M1

| 부위 | 성조 수컷 | 성조 암컷 | 근거 |
|---|---|---|---|
| 머리 | 정수리·뒷목이 **푸른 광택이 있는 검정**. 눈앞·턱밑·멱까지 검정이 이어져 **흰 뺨을 둘러싼다** | 같은 무늬, 검정의 광택이 적다 | ✔ SRC-004 · SRC-027 |
| 뒷목 | 검은 머리 뒤에 **흰 점**(뒷목) | 같음 | ✔ SRC-027 |
| 등 | 회색 계열. **뒷목과 등의 경계만** 올리브 황록색 — 등 전체가 초록이 아니다 | 같음 | ? SRC-004 (E) 단독 — 회색 등은 SRC-027이 홍콩 아종에 대해 적음 |
| 날개 | 큰날개덮깃 끝이 희어 **흰 날개띠 한 줄** | 같음 | ✔ SRC-027 |
| 배 | **흐린 회백색**. 노랗지 않다 | 같음 | ✔ SRC-027 |
| 세로줄 | 멱의 검정이 배 가운데를 지나 **아래꼬리덮깃까지** 이어진다. **굵고, 두 다리 사이에서 넓게 퍼진다** | **가늘다**. 멱의 검정도 범위가 좁다 | ✔ SRC-004 · SRC-027 |
| 크기 | 12~14cm | 같음 | ✔ SRC-027 |

| 나이·단계 | 특징 | 근거 |
|---|---|---|
| 어린 새 (이소 후~첫 털갈이) | 무늬는 성조와 같지만 **위는 올리브빛, 아래는 노르스름**하고 **입가(부리 끝 모서리)가 희게 두드러진다**. 검정이 흐리다(회흑색) | ✔ SRC-027 |
| 알 | **흰 바탕에 잿빛·붉은 갈색 잔점** | ? SRC-004 (E) 단독 |
| 둥지 안 새끼 | (출처 없음 — M1 도감 전에 채움) | — |
| 번식깃·비번식깃 | 계절에 따른 깃 차이를 다룬 출처 없음. **같은 깃으로 그린다** | — |

### 박새 — 생성 AI가 틀리기 쉬운 것 (그림 거부 기준)

| # | 틀린 그림 | 맞는 그림 |
|---|---|---|
| 1 | 성조의 **배가 노랗다** (화풍 테스트 9장 모두 — `docs/art/style-options.md` 6.3) | 성조 배는 회백색. 노르스름한 배는 **어린 새만** |
| 2 | 세로줄이 **가슴에서 끊긴다**, 또는 넥타이처럼 짧다 | 멱부터 **아래꼬리덮깃까지** 한 줄로 이어진다 |
| 3 | 세로줄 굵기가 암수 같다 | 수컷 = 굵고 다리 사이에서 넓다 / 암컷 = 가늘다. 짝을 한 화면에 그릴 때 특히 |
| 4 | 등 전체가 초록·노랑 | 회색 등, 초록은 뒷목 아래 경계에만 (약하게) |
| 5 | 흰 뺨이 머리 뒤로 열려 있다 | 흰 뺨은 검정에 **둘러싸인** 섬 |
| 6 | 흰 날개띠가 없다 | 날개에 흰 띠 한 줄 |

> 프롬프트 팁(아트용): "Japanese tit" 또는 "*Parus minor*"를 쓰고, "Great tit"은 쓰지 않는다. 배 색은 "greyish-white belly, no yellow"처럼 **부정형까지** 적는다.

## 2. 꼬마물떼새 (*Charadrius dubius*) — M5

| 부위·단계 | 특징 | 근거 |
|---|---|---|
| 눈 | 성조는 **노란 눈테**가 뚜렷하다 | ✔ SRC-029 |
| 머리 | 성조는 머리의 검은 무늬가 뚜렷하다(**수컷이 더**). 암컷과 비번식깃은 흐리고 머리 무늬에 **갈색**이 섞인다 | ✔ SRC-029 |
| 가슴띠 | 성조는 검은 가슴띠 | ? SRC-029는 어린 새가 "끊긴 가슴띠"라고만 적는다(성조는 이어진 띠라는 대비) |
| 부리·다리 | 부리는 거의 검정, 다리는 옅은 색 | ✔ SRC-029 |
| 날 때 | **날개띠가 없다** | ✔ SRC-029 |
| 크기 | 14~17cm | ✔ SRC-029 |
| 어린 새 | 윗면 깃 가장자리가 옅다, **가슴띠가 끊긴다**, 눈테가 흐리다 | ✔ SRC-029 |
| 알·새끼 | 자갈과 닮은 위장 (gdd 8.5) | ? 출처 없음 — M5 |

틀리기 쉬운 것: 눈테를 빼먹는다 / 날 때 날개에 흰 띠를 그린다.
