## 1. 상태 표시

| 상태 | 뜻 |
|---|---|
| **열림** | 출처가 E·D등급 단독이거나 없다. 데이터에는 `needs-review` |
| **전문가 질문** | 문헌으로 못 풀어 `type:human` 이슈(#84)로 대표에게 넘겼다 |
| **나중** | 그 종을 만드는 마일스톤(M4·M5)에 조사한다. 지금 쓰는 데이터가 없다(01-collaboration 15장) |
| **해결** | A·B등급 출처를 찾았거나 전문가 답을 받았다. 데이터를 `verified`로 바꿨다 |
| **규칙** | 사실 문제가 아니라 쓰는 방법의 문제. 규칙을 정해 닫았다 |

**전문가 답을 출처로 쓰는 법** — 답한 사람의 이름(또는 동아리 이름)·날짜·질문 번호로 `sources.md`에 `SRC-번호`를 받는다. 등급은 **C**(전문 도감과 같게)로 단독 근거가 될 수 있다. "모르겠다"·"지역마다 다르다"는 답은 그대로 `note`에 적고 `needs-review`를 유지한다.
