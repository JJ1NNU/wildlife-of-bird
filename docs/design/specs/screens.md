# 화면별 정보 요구사항

- 버전: v1 (2026-10-04, #22 · #52)
- 소유: 게임디자인 / 화면 설계: 아트·UX(`docs/ux/screens.md`, 와이어프레임) / 구현: 클라이언트
- 기준: 기획서 3장 원칙 5 **"확률을 보여주고 고르게 한다"**, `01-formulas` 7장(표시 형식)

## 1. 이 문서가 정하는 것

화면마다 **플레이어가 결정하려면 무엇을 봐야 하는가**. 화면의 배치·모양·흐름은 아트의 `docs/ux/screens.md`가 정한다. 둘이 어긋나면 이 문서가 우선이다(01-collaboration 13장).

- 범위: **M1 박새**에 쓰는 화면만. 화면 ID는 `docs/ux/screens.md` 2장을 따른다.
- 화면은 확률·점수를 계산하지 않는다. 숫자는 모두 엔진이 준다(`preview`·`getView`, `03-contracts` 1.5). 엔진이 아직 주지 않는 값은 4장에 모았다.

## 2. 공통 표시 규칙

| 무엇 | 형식 | 근거 |
|---|---|---|
| 사망 위험 · 둥지 손실 · 새끼 사망 확률 | 0.1% 미만 → "0.1% 미만" / 10% 미만 → 소수 첫째 자리 % / 그 이상 → 정수 %. 색 띠 낮음·보통·높음 | `01-formulas` 7.1 |
| 에너지 변화 | 부호 붙은 정수 하나 | `01-formulas` 7.2 |
| 예상 스탯 상승 | 소수 첫째 자리. 등급이 바뀌면 "C → B" | `01-formulas` 7.3 |
| 판정형 선택지 성공 확률 | 정수 % | `03-events` 5.3 |
| 짝 지시 수락률 | **등급만** — 높음·보통·낮음·불가+이유. 숫자 없음 | `01-formulas` 7.4 |
| 스탯 | 등급 G~S. 상세 화면(S-15)에서만 0~100 | gdd 5장 |
| 숨은 값(짝의 잠재력·성격, 새끼의 잠재력) | 정확한 값을 보여주지 않는다. 등급 **범위**나 정직한 신호로 | gdd 5.4 · 7.2 |

- **보여준 확률은 실제 판정 확률과 같다.** 화면에서 반올림만 한다.
- 글(`text`)에는 숫자를 쓰지 않는다. 숫자는 화면이 엔진 값으로 붙인다(`03-events` 5.3).

## 3. 화면별

### S-10 메인 턴 — 행동 고르기 (매 단계)

| 정보 | 왜 |
|---|---|
| 시기·국면·계절, 총 번식 수 | 지금 어디인지 |
| 에너지 / 지방 상한, 깃털 | 에너지 0은 확정 사망(`00-core-loop` B-1). 배고픔·지방·깃털이 위험을 바꾼다 |
| **굶주림 경고** — 에너지 / 지방 상한 < `energy.starvationWarnRatio` | 아사 직전임을 놓치지 않게 |
| 현재 장소: 먹이·경쟁 등급, 연속 체류(고갈), 위험 | "머물기 vs 옮기기"의 근거(`00-core-loop` 3.2) |
| 행동마다 **에너지 변화 · 위험% · 예상 성장** 셋 | 판정 순서가 에너지 → 위험이라 위험%만으로는 결정할 수 없다. #52 |
| `옮기기` 줄 → 펼치면 목적지 카드(최대 4개): 이동 에너지 비용 · 도착지 위험% · 먹이·경쟁 등급 | 행동과 같은 자로 비교(#38). 펼침은 화면만의 상태, 입력은 1회 |
| 이번 시기의 환경 카드(있으면) | 그 시기의 `foodMod`·`riskMod`가 미리보기 값에 이미 들어 있다는 것을 알 수 있게 |

### S-12 판정 결과 (S-10 위에 겹침)

- 예상 대비 실제: 에너지 변화, 스탯 상승. 위험 판정은 "살아남음"만(확률을 다시 보여줄 필요는 없다).
- 짝 지시를 했으면 수락/거절과 그 결과(`00-core-loop` B-6).

### S-13 이벤트 카드

- 제목·본문, 선택지마다:
  - 고정 효과: 효과마다 실제 숫자("에너지 −12", "사망 위험 3%", "둥지를 잃을 위험 30%")
  - 판정형: "경계 판정 90% — 성공: … / 실패: …"
- `fledgeEarly`가 든 선택지: "새끼들이 지금 둥지를 떠난다" + 함께 붙은 `chickLoss`의 마리 수(올림, `03-events` 6.1).

### S-15 개체 상세

- 스탯 6개: 현재값 / 잠재력의 **등급 범위**, 적성 등급
- 나이, 노화 시작 나이(`species.agingStartAge`)와 지금의 노화 위험 배율
- 부상(남은 단계), 이번 시기에 걸린 `riskMod`·`foodMod`

### S-20 짝 후보 (관문 — `pairing` 첫 단계)

- 후보마다: 신호 4개 — 깃 선명도(등급) · 노래(등급) · 나이(1년생/성조) · 성격 힌트(글) — 와 **나를 받아들일지(예 / 아니오)**. 아니오인 카드는 고를 수 없고 이유("노래가 더 필요하다")를 보인다. `04-breeding` 2.3 · 2.4
- 지난 짝이 있으면 맨 앞 카드: 스탯 등급 범위, 성격(확인), 유대. 재결합하면 유대가 오른다(`04-breeding` 2.2).

### S-21 짝 지시 · S-22 육아 방침 · S-23 둥지 진행 (번식 단계)

| 화면 | 정보 |
|---|---|
| S-21 짝 지시 | 둥지 국면 첫 단계에만. [지시 없음] + 지시마다 수락률 **등급**(숫자 없음), 불가면 이유 + 도움. 짝 유대·성격(힌트/확인). 거절되면 "짝이 ~ 대신 ~ 했어요 (효과 −N%)" (`04-breeding` 3장) |
| S-22 육아 방침 | 7항목(`04-breeding` 6.1)과 방침 조합의 **이소 기대 수**(소수 첫째 자리)·**내 번식 비용**(단계당 에너지, 정수) — 항목을 바꿀 때마다 다시 계산(6.4). 설정은 `nestling` 첫 단계, 조정은 `postFledge` 첫 단계에 한 번(6.2) |
| S-23 둥지 진행 | 국면 스텝퍼 **6칸**: 짝 → 둥지 → 산란 → 포란 → 육추 → 이소·돌봄, 끝 표시 **독립**. 단계마다 둥지 손실 위험%, 살아 있는 알·새끼 수 |

- 스텝퍼는 국면(`00-core-loop` 2.2)과 1:1이다. '이소'는 국면이 아니라 육추가 끝나는 순간이다. 재번식(`00-core-loop` 4.4)은 `nestSite`부터 다시 시작하고 '짝' 칸은 완료로 둔다.
- 짝이 죽어 단독 육아가 되면 S-23에 **둥지 포기** 선택지(`00-core-loop` B-2).

**관문 패널** (S-22·S-23 안에 넣어도 된다 — 배치는 아트)

| 관문 | 열리는 때 (`00-core-loop` 4.6) | 정보 |
|---|---|---|
| 둥지 자리 | `nestSite` 첫 단계 | 구멍마다 둥지 손실 위험%, 깊은 구멍이면 차지할 확률(정수 %) — `04-breeding` 4장 |
| 산란수 | `laying` 첫 단계 | 산란수마다 이소 기대 수 · 은수저 지수(많이 낳으면 1마리 몫이 준다, `01-formulas` 6.1) · 단계당 급이 비용 |
| 육아 방침 설정 | `nestling` 첫 단계 | S-22와 같다 |

### S-24 독립 · 계승 결정 (관문 — `postFledge` 마지막 단계)

- **먼저 "총 번식 수 +1 확정"을 보여 준다.** 계승을 고르든 잔류하든 이미 확정이다(`00-core-loop` 6.1).
- 새끼 카드마다: 성별, 잠재력 **등급 범위**(예 "C~B"), 은수저 지수, 첫 겨울 위험 보정(`01-formulas` 6.3)
- 현재 개체: 나이, 노화 위험 배율, 짝 유대, 잔류 시 다음 1년 생존 예상
- 잔류를 고르면 이어서 **2차 번식 여부**(`00-core-loop` 4.4의 조건이 참일 때만): 에너지 비용(`species.secondBrood.energyCost`), "털갈이 4단계가 번식으로 바뀐다 → 겨울 깃털 부족" 안내
- 계승은 되돌릴 수 없다 — 확인을 한 번 더(아트 `screens.md` 3장)
- 잠재력 범위의 폭 규칙과 넘어가는 것·초기화되는 것은 `05-inheritance`(M1). 잠정(#22): 실제 등급을 포함하는 연속 2등급

### S-30 게임 오버 · 생애 기록

- 최종 점수 = 총 번식 수(정산 없음), 사망 원인(`00-core-loop` 8장 코드를 글로), 부가 기록(`02-scoring` 4장).

### S-01 · S-02 · S-03 · S-40

- S-02 종 선택: M1은 박새 하나 — 평균 런 길이(`targets.avgRunYears`)만.
- S-03 첫 개체: 성별 선택 여부는 gdd 15장 미결 4 → `05-inheritance`(M1). 잠정(#22): 성별을 보여만 준다.
- S-01·S-40: 결정 정보 없음.

### M1에서 빼는 화면

- **S-11 지도**: 장소 선택은 S-10의 옮기기 펼침에서 끝난다(#38). S-11은 정보용 지도가 되므로 M2 이후.
