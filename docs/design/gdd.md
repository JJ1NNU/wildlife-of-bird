## 1. 프로젝트 개요

### 1.1 한 줄 컨셉
한국을 찾는 실제 야생조류 한 마리로 태어나, 턴제로 스탯을 키우고 번식에 성공하며, 새끼에게 계승하면서 가문을 이어가는 **생태 기반 커리어형 육성 게임**.

### 1.2 영감
- 축구·야구 선수 커리어 모드(선수 생성 → 성장 → 통산 기록)
- 우마무스메 / 실황파워프로 석세스(턴제 육성, 목표, 실패율, 계승)
- 프린세스 메이커(기간별 방침·스케줄, 스탯 조합에 따른 멀티 엔딩)
- Shelter 2(새끼 중 하나로 다음 세대를 이어감, 가계도)

### 1.3 개발 조건 [확정]
- 1인 취미 프로젝트, 처음 해 보는 게임 개발. 친구들과 공유해서 노는 용도.
- 단, **게임성은 출시해도 될 수준**을 목표로 한다.
- 모바일 기반. (프로젝트 설명상 웹 기반 → 모바일 웹/PWA 권장, 13장)
- **과금 요소 없음.** 점수는 오로지 전략, 게임 이해도, 운으로만 오른다.

### 1.4 시장 포지션
기존 모바일 '새' 게임은 대부분 3D 자유비행 생존 시뮬레이터이거나 펫 돌보기+퍼즐 캐주얼이다. 실제 생태에 기반한 턴제 커리어 육성은 비어 있는 자리다.

## 2. 확정 결정사항 목록 [확정]

1. 장르: **턴제 기반 계획·전략 육성**. 개체 단위로 훈련·성장을 통해 스탯이 계속 오른다.
2. **세대 계승**: 새끼에게 특성이 계승되며, 세대를 거듭할수록 더 강하고 잘 자라는 개체가 태어나는 발전 구조. (단, 생태적으로 맞게 — 5.4장)
3. **통산 기록·평가가 남고, 리더보드로 경쟁**한다.
4. 프린세스 메이커식 요소를 참고한다.
5. 종 조건: "한국에서 태어나기"가 아니라 **"한국을 주기적으로 방문"** 하는 종이면 된다. (텃새·여름철새·겨울철새·나그네새 모두 가능)
6. **다양한 종 선택**. 종마다 **수명 ↔ 새끼 수 트레이드오프**로 플레이스타일이 갈린다.
7. **사람·도시 등 인공물 비중 최소화.** 자연의 험난함이 최우선 배경. 인공 요소는 드문 이벤트로만 (예: 기러기가 오던 논이 개발됨, 서해 갯벌 매립으로 도요물떼새가 서식지를 잃음).
8. 생태 기반 재미 요소를 다양하게 넣는다 (10장 카탈로그).
9. 과금 없음.
10. 1인 취미, 친구 공유, 출시급 게임성.
11. **1년 플레이타임 40분~1시간.** 한 생애 ≠ 1년.
12. **매년 번식 시도 → 성공하면 새끼를 키움 → 새끼가 독립할 때 특성·스탯을 보고 "계승(새끼로 갈아탐)" 또는 "이 개체로 1년 더"를 선택.**
13. **현재 조작 중인 개체가 죽으면 게임 오버.**
14. 난이도: **모든 유저가 평균 10년 이내에 게임 오버**를 겪는 수준. 아주 잘하고 운도 좋으면 계승을 반복해 수십 년 플레이도 가능하지만, 결국 언젠가는 운이 나빠 끝난다.
15. **번식기에는 짝에게 지시 가능.** 짝은 성격·종 특성·성별 등에 따라 거절하고 독단 행동을 할 수 있다(생태학 근거 반영). **거절이 나쁜 이벤트로 이어지지는 않고, 약간 손해 보는 정도**로만.
16. 새끼에게는 지시하지 않고, **키우는 방식**으로 진행한다.
17. 첫 구현은 **4종**. 난이도·생애 주기·저점·고점이 다양하고, 어느 하나 특출나게 좋지 않게 밸런스.
18. **최종 점수 = "총 번식 수"**. 4종의 밸런스는 이 점수의 관점에서 동등해야 한다. 종별 점수 계수(가중치)는 쓰지 않는다. (정의: 11장, 밸런스 구조: 8.3장)
19. **개발 체계**: GitHub 저장소 + Claude Code. 7개 부서 AI 에이전트(PM, 게임디자인, 생태·콘텐츠, 엔진, 클라이언트·배포, 아트·UX, QA·밸런스)가 협업하고, 사용자는 대표로서 최종 결정한다. 일정·작업 분배는 PM 에이전트. (`docs/studio/01-collaboration.md`)
20. **기술 스택**: 엔진 부서(기술 리드)가 ADR-001로 결정한다. 조건: 모바일 웹 + PWA, 엔진은 UI와 분리되어 Node에서도 실행, 무료 정적 호스팅. (`docs/agents/engine.md` 8장)
21. **그림**: 대표가 이미지 생성 AI로 만들고, 아트·UX 부서가 화풍·명세·프롬프트·선별·후처리·통합을 맡는다. 새 그림은 생태·콘텐츠의 생태 검토를 통과해야 쓴다. (`docs/agents/art.md` 7장)
22. 외부 서비스는 **무료 등급만**. 유료 전환은 대표 승인.
23. **단순성 원칙**: 모든 구현 단계에서 과도한 테스트와, 확인되지 않은 요구를 근거로 한 선제적 복잡도(미리 만드는 추상화·일반화·옵션·확장 구조)를 금지한다. (`docs/studio/01-collaboration.md` 15장)

## 3. 디자인 원칙

1. **생태적 정확성**: 메카닉은 실제 생태·행동 연구에 근거한다. 게임을 위해 현실을 비틀 때는 문서에 명시한다(예: 4.5장 난이도 보정).
2. **라마르크식 유전 금지**: 부모가 훈련으로 올린 스탯이 그대로 유전되지 않는다. 대신 유전·성장 환경·문화·플레이어 지식의 네 경로로 계승한다.
3. **자연이 주인공**: 위험의 대부분은 포식자·날씨·계절·먹이·질병·서식지 변화. 사람은 드문 큰 사건.
4. **정답이 하나가 아닌 트레이드오프**: 거의 모든 선택에 대가가 있다. 최적값은 환경에 따라 달라지고, 환경은 세대마다 변한다.
5. **확률을 보여주고 고르게 한다**: 우마무스메처럼 위험·성공 확률을 미리 보여준다. 전략의 재미는 정보를 보고 내리는 결정에서 나온다.
6. **실력 + 이해도 + 운**: 과금 없음. 운의 영향은 있지만, 좋은 판단이 장기적으로 반드시 이긴다.
7. **실패해도 할 일이 남는 구조**: 번식 실패, 짝의 거절 등이 곧바로 파국이 되지 않게.
8. **종 간 공정은 점수 보정이 아니라 생애 구조로**: 같은 실력이면 어떤 종을 골라도 총 번식 수의 기대값이 같도록, 번식 기회·성공률·런 길이·계승 공백을 설계로 맞춘다.

## 4. 게임 구조

### 4.1 런(run) 구조 [확정 + 초안]

```
[개체 생성/선택] → [1년 진행: 24시기]
    → 번식 시도 → (성공) 육아 → 새끼 독립
        → [결정] 계승: 새끼 중 하나로 갈아탐 / 잔류: 이 개체로 1년 더
    → (실패) 계승 불가, 이 개체로 계속
→ ... 반복 ...
→ 조작 중인 개체 사망 = 게임 오버 → 생애·가문 기록, 점수, 리더보드
```

- **계승 결정 시점은 "새끼가 독립하는 순간"** 이며 종마다 다르다(8장). 박새처럼 연 2회 번식 가능한 종은 1년에 계승 기회가 2번 있을 수 있다.
- **계승하면**: 새끼 개체로 조작이 넘어간다. 새끼는 경험이 적고, 종에 따라 첫 겨울·첫 이동·미성숙기(번식 못 하는 해) 같은 고위험 구간을 다시 겪는다.
- **잔류하면**: 경험·짝 유대·영역·지역 지식을 유지한다. 대신 나이가 들수록 노화로 위험이 커진다.
- 계승으로 떠난 부모 개체는 NPC가 되어 시뮬레이션으로 살아간다(겨울 무리나 콜로니에서 마주칠 수 있음). 이후 그 개체의 번식은 점수에 넣지 않는다. [초안]
- 번식에 실패한 해에는 계승할 새끼가 없으므로 잔류만 가능하다 → 늙은 개체로 실패가 이어지면 위험이 누적된다.
- 계승한 새끼가 번식 연령 전에 죽어도 게임 오버.
- **런 시작 상태** [초안]: 모든 종은 '첫 번식기를 앞둔 젊은 성조'로 시작한다. 느린 종이 미성숙기부터 시작해 손해 보지 않도록.
- **점수 확정 시점**: 새끼가 독립하는 순간(=계승 결정 화면) 그 번식이 성공으로 확정되어 총 번식 수 +1 (11장).

### 4.2 시간 구조 [초안]

- **1년 = 24시기(반 달 단위, 상반/하반).**
- 목표 플레이타임 1년 40~60분 [확정]을 맞추기 위해, 중요한 시기는 세부 단계로 쪼갠다.
  - 평시(겨울·가을 등): 1시기 = 1단계
  - 번식기: 1시기 = 2~3단계 (산란·포란·육추를 촘촘하게)
  - 이동기: 이동 구간(leg)마다 1단계
- 1년 결정 횟수 목표: 약 60~90회, 결정당 평균 30~50초.
- 매 단계 자동 저장, 언제든 중단·재개.

### 4.3 한 단계(턴)의 흐름 [초안]

1. **환경 카드**: 계절, 날씨, 사건(해거리, 장마, 한파, 포식자 출현 등)
2. **장소 선택**: 지도 노드(숲, 덤불, 하천 자갈밭, 갯벌, 섬, 논, 습지 등). 노드마다 먹이량·위험·경쟁 수치.
3. **행동 1개**: 채식 / 훈련(비행·노래·춤 등) / 휴식 / 사회(무리·서열·구애) / 탐색(새 장소 정보) / 종 고유 행동
4. **(번식기) 짝 지시 + 육아 방침 조정** (7장)
5. **판정**: 에너지 수지, 스탯 상승, 위험 판정(포식·사고·질병)
6. **이벤트** (선택지형 카드 또는 짧은 미니게임)

- 행동을 고르기 전에 **예상 위험%와 예상 성장량**을 보여준다.

### 4.4 계절 방침과 생애 칭호 (프린세스 메이커 요소) [초안]

- 계절마다 **방침**을 하나 정한다. 그 계절 동안 보정치가 붙는다.
  - 예) 가을: 지방 축적 / 먹이 저장 / 서열 경쟁 / 이동 준비
  - 예) 겨울: 체온 절약 / 무리 생활 / 영역 유지
- 개체가 죽거나 계승으로 떠날 때, 스탯과 행적 조합으로 **생애 칭호(멀티 엔딩)** 가 정해진다.
  - 예) "다섯 번의 겨울을 난 새", "숲의 경보관", "대가족", "2만 km를 난 새", "평생의 짝"

### 4.5 난이도 목표와 보정 방법 [확정 목표 + 초안 방법]

- 목표: **어떤 종이든 평균 플레이어의 게임 오버까지 평균 10년 이내.**
- 종별 평균 런 길이는 생애 속도에 맞춰 다르게 둔다(빠른 종은 짧고 굵게, 느린 종은 길고 꾸준하게). 설계 목표값: 박새 약 4.5년, 꼬마물떼새 약 5.5년, 저어새 약 7.5년, 두루미 약 8.5년. 이 차이가 총 번식 수 기대값을 같게 만드는 축 중 하나다(8.3장).
- 숙련 + 운: 수십 년 가능. 그러나 어떤 런도 영원하지 않다(위험 하한이 0이 아님).
- 보정은 **봇 시뮬레이션**으로 한다(13장).
  - 무작위 봇: 평균 1~3년 안에 게임 오버
  - 평균 플레이어 봇(합리적 휴리스틱): 위 종별 목표 런 길이
  - 숙련 봇: 평균 20년 이상, 상위권은 수십 년
- **생태와의 의도적 타협(명시)**:
  - NPC(짝, 새끼, 이웃, 경쟁자)는 실제 야생 생존율에 가깝게 시뮬레이션한다.
  - 플레이어 개체는 좋은 판단으로 야생 평균보다 훨씬 오래 살 수 있다. 특히 빠른 종(박새)은 실제 야생 성조 생존율보다 플레이어 생존율이 높게 설계된다. 이는 "플레이어가 최선의 판단을 하는 개체"라는 게임적 허용이다.
  - 느린 종(두루미)은 평균 플레이어 생존율을 실제 성조 생존율에 가깝게 두면 목표(평균 10년 이내)와 자연스럽게 맞는다.

## 5. 개체 시스템

### 5.1 기본 스탯 [초안]
훈련·경험으로 오르며, 상한은 유전 잠재력이 정한다. 표기는 0~100(내부) / 등급 G~S(표시).

| 스탯 | 효과 |
|---|---|
| 비행 | 이동 비용↓, 포식자 회피, 이동 속도 |
| 채식 | 먹이 획득 효율 |
| 경계 | 포식자 탐지, 경보음 해석, 위험 확률↓ |
| 체력 | 에너지(지방) 상한, 추위·장거리 지구력 |
| 과시 | 노래·춤·깃 과시 → 짝 획득, 영역, 서열 |
| 사회 | 무리 협력, 서열, **짝의 수락률↑** |
| 항법 | 철새 전용: 이동 경로 효율, 기상 판단 |

숨은/누적 수치
- **경험**: 나이와 함께 오름. 위험 판단, 바람 예보 정확도 등에 보정. 계승 시 초기화(가족 이동 종은 일부 문화 계승).
- **지역 지식**: 지도 노드별 정보 공개도(먹이·위험·안전한 잠자리).
- **짝 유대**: 짝별 수치. 협력·수락률에 영향.

### 5.2 자원
- **에너지(체지방)**: 0~상한. 0이 되면 아사 판정.
- **깃털 상태**: 낮으면 비행 효율↓, 체온 유지↓. 털갈이·목욕으로 관리.
- **부상**: 스탯 일시 저하, 휴식으로 회복(우마무스메 양호실 자리).

### 5.3 선천 특성(유전)과 트레이드오프 [초안]
| 특성 | 장점 | 대가 |
|---|---|---|
| 체격 ↑ | 추위·싸움·서열 유리 | 먹어야 할 양 ↑ |
| 깃 선명도 ↑ | 구애·짝 획득 유리 | 포식자 눈에 잘 띔 |
| 날개 뾰족함 ↑ | 장거리 비행 유리 | 기동성 ↓(포식자 회피) |
| 대담성 ↑ | 새 먹이터 빨리 찾음, 경쟁 유리 | 위험 노출 ↑ |
| 스탯별 잠재력 | 해당 스탯 상한·성장률 | — |
| 성별 | 종별 역할 차이(7장) | — |

- 최적값은 환경에 따라 다르고 환경은 세대마다 변한다 → "강해진다" = "지금 환경에 더 잘 맞아진다". 이것이 자연선택이며 전략 깊이의 원천.

### 5.4 계승 — 세대가 갈수록 강해지는 구조 [확정 방향 + 초안 공식]

부모의 성과가 자식에게 가는 네 경로:

1. **유전(잠재력)**
   - 공식 초안: `자식 잠재력 = 종 평균 + h² × ((어미 + 아비)/2 − 종 평균) + 무작위 변이`
     - h²(유전율)는 특성별 0.3~0.5 정도로 시작(조정 대상).
     - 종 평균으로 끌려가는 회귀가 있으므로, **매 세대 좋은 짝 선택과 좋은 새끼 선택**을 해야 계보가 계속 강해진다.
   - 짝의 잠재력은 직접 보이지 않고 **정직한 신호**(깃 선명도, 노래 템포, 춤, 영역 질)로 추정한다 → 실력 + 운.
2. **성장 환경(은수저 효과)**
   - 새끼 시절 잘 먹고 자란 정도(은수저 지수 0~1)가 출발 컨디션·성장률·첫해 생존율을 올린다.
   - 생태 근거: 두루미 연구에서 몸집이 큰 새끼일수록 첫 겨울에 살아서 관찰될 가능성이 높았다.
   - 부모의 채식·경계 스탯이 높으면 새끼를 더 잘 먹일 수 있다 → 부모의 노력이 다음 세대로 가는 정당한 통로.
   - 초기 스탯 초안: `시작 스탯 = 잠재력 × (0.2 + 0.3 × 은수저 지수) + 학습 보너스`
3. **문화(배워서 전해지는 것)**
   - 가족 단위로 이동·월동하는 종(두루미, 저어새는 부분적)은 새끼가 부모를 따라 경로·월동지·잠자리를 배운다 → 지역 지식 일부 계승.
   - 노래를 배우는 명금류(박새)는 아비·이웃의 노래를 배운다.
4. **플레이어 지식(메타)**
   - 도감(포식자, 먹이, 장소, 이벤트), 업적. 런이 끝나도 남는다. 수치 보너스가 아니라 정보 해금 위주.

### 5.5 노화 [초안]
- 종별 노화 시작 나이 이후 위험 배율이 증가하고 신체 스탯이 서서히 하락한다. 경험은 계속 오른다.
- 시작 나이(설계값, 시뮬레이션으로 조정): 박새 3세~, 꼬마물떼새 5세~, 저어새 12세~, 두루미 20세~.

## 6. 위험·에너지 모델 (공식 초안) [초안]

### 6.1 에너지
```
다음 에너지 = 현재 에너지 + 섭취 − 소비
섭취 = 장소 먹이량(계절·이벤트) × 채식 효율(채식 스탯, 경험) × 행동 계수 × (1 − 경쟁 보정)
소비 = 기초 대사(종, 기온, 밤 길이) + 행동 비용 + 번식 비용(포란·급이 강도) + 털갈이 비용
에너지 ≤ 지방 상한(체력)
```
- 겨울: 낮이 짧아 섭취 기회↓, 밤 비용↑.
- **지방 다이얼**: 목표 체지방을 정하면 채식량이 자동 조절. 지방↑ = 아사 위험↓, 포식 위험↑(몸이 무거움). 굶주림-포식 트레이드오프.

### 6.2 포식·사고 위험
```
위험% = 장소 위험 × 포식자 활동(계절·이벤트)
        × (1 − 경계 보정) × 무리 보정 × 지방(무게) 보정
        × 배고픔 보정 × 깃털 보정 × 노화 보정
        × (포식자 상성 대응 성공 시 크게 감소)
```
- 배고플수록 위험한 장소를 고를 수밖에 없게 됨 → 실제 동물의 상태 의존적 위험 감수.
- 플레이어에게는 반올림된 %로 표시.

## 7. 번식 시스템

### 7.1 짝 맺기 [초안]
- 번식기 시작 시 후보 2~4마리. 보이는 정보: 깃 선명도, 과시 수준, 영역 질(해당 시), 나이 추정, 성격 힌트.
- **상호 선택**: 내 과시·영역이 약하면 좋은 후보가 나를 받아주지 않을 수 있다(나쁜 이벤트가 아니라 선택지가 줄어드는 것).
- 관찰 행동에 턴을 쓰면 후보의 정보가 더 드러난다.
- 종별
  - 박새: 짝이 둘 다 살아 있으면 재결합 가능. 번식 실패 후에는 갈라설 확률↑.
  - 꼬마물떼새: 수컷이 오목한 둥지 자리를 만들고, 암컷이 그 둥지를 받아들여야 짝이 성립한다.
  - 저어새: 콜로니에서 번식기마다 짝 형성(재결합 가능) [검수 필요].
  - 두루미: 평생 짝이 기본. 짝이 죽거나, 번식 실패가 반복될 때만 드물게 재짝짓기.

### 7.2 짝 지시 시스템 [확정 방향 + 초안 규칙]

**지시 가능한 항목(단계별)**
- 영역·둥지: 둥지 자리 제안, 재료 운반 분담, 영역 순찰
- 산란 전: 구애 먹이 요청(암컷 플레이어가 수컷에게)
- 포란: 교대 리듬(짧게 자주 / 길게 드물게), 포란 중 먹이 공급 요청
- 육추: 먹이 구역 분담(가까운 곳 / 먼 곳), 급이 강도, 경계 담당
- 위험: 모빙·다친 척 유인 참여, 둥지 방어
- 이소 후: 새끼 나눠 맡기, 돌봄 연장
- 이동(가족 이동 종): 출발 시기·경로 제안

**수락 확률 모델**
```
수락률 = clamp( 종·성별 역할 적합도 × 성격 × 짝의 컨디션 × 유대 × 상호성 , 5%, 95% )
```
| 요인 | 내용 | 생태 근거 |
|---|---|---|
| 종·성별 역할 | 그 종에서 그 성별이 원래 하는 일이면 높고, 아니면 낮음. 생물학적으로 불가능하면 '불가'로 표시하고 이유 설명(교육 요소). 예: 박새 수컷에게 포란 요청 → 불가(박새는 암컷이 포란). | 종별 성 역할 |
| 성격 | 대담한 짝은 위험한 일(모빙, 먼 먹이터)에 잘 응하고, 소심한 짝은 거절. 탐색 성향이 강하면 새 장소 제안에 잘 응함. | 동물 성격(대담-소심) 연구 |
| 짝의 컨디션 | 배고픈 짝은 자기 먹이부터 챙겨 급이 요청을 거절하기 쉬움. | 자기 유지 vs 새끼 투자 |
| 유대 | 함께한 해가 길고 협력이 잘 될수록 ↑. | 장수종의 짝 친숙도 효과 |
| 상호성 | 내가 최근에 먹이를 날랐으면 짝도 잘 응함. 내가 게으르면 짝도 노력을 줄임(부분적으로 맞춤). | 박새 부모는 짝이 먹이를 주고 간 뒤 급이 속도를 높이고, 자기가 준 뒤엔 늦추며 번갈아 먹이는 경향(조건부 협력) |
| 성 갈등(기본) | 서로 상대가 더 하길 바라는 기본 저항. 비용이 큰 요청일수록 수락률↓. | 양육 투자를 둘러싼 성 갈등 |

- 표시: 지시 전에 **높음(70%+) / 보통(40~70%) / 낮음(40% 미만) / 불가** 와 이유 아이콘.
- **거절 처리 [확정]**: 짝은 자기가 선호하는 **대안 행동**을 한다. 결과는 원래 지시의 70~90% 효과이거나 다른 작은 이득. **파국적 이벤트(둥지 포기, 이혼 등)는 거절로 발생하지 않는다.** 이혼은 번식 실패 누적에서만 확률이 생긴다.
  - 예) "짝이 먼 갯벌 대신 가까운 얕은 물에서 먹이를 구했어요. (먹이 공급 −10%)"
- **짝 성격 학습**: 상호작용할수록 짝의 숨은 성격이 드러난다(숨김 → 힌트 → 확인). 오래된 짝일수록 지시를 정확히 맞출 수 있다(두루미의 강점).

**종별 짝 역할 요약**
| 종 | 둥지 | 포란 | 육추 | 특이점 |
|---|---|---|---|---|
| 박새 | 암컷이 짓고 위치 최종 결정 | 암컷 단독, 수컷은 포란 중인 암컷에게 먹이 공급 | 암수 번갈아 급이 | 구애 급이가 암컷 컨디션에 영향 |
| 꼬마물떼새 | 수컷이 오목자리 여러 개, 암컷이 선택 | 암수 교대(24~28일) | 새끼가 스스로 먹음, 부모는 호위·체온 보호 | 더울 때 물을 적셔 알 식히기, 다친 척 유인 |
| 저어새 | 콜로니 내 자리, 재료 운반·짓기 분담 [검수 필요] | 암수(약 26일) | 암수가 게워서 먹임(약 40일) | 콜로니 이웃 관계 |
| 두루미 | 암수가 함께 | 암수 교대(29~34일) | 부화 후 암컷이 주로 먹이, 수컷이 방어 | 평생 짝, 춤·이중창으로 유대 |

### 7.3 육아 방식 — 새끼는 지시하지 않고 키우는 방식으로 [확정 방향 + 초안 항목]

육아 방침 패널(육추 시작 시 설정, 단계마다 조정 가능):

1. **급이 강도** (자기 유지 ↔ 새끼 급이): 높으면 새끼 성장↑, 부모 에너지·깃털↓, 번식 후 생존↓ (번식 비용).
2. **먹이 배분** (경쟁 허용 ↔ 고르게): 경쟁 허용 = 가장 강한 새끼가 크게 자람(좋은 후계 후보), 막내 손실 위험. 고르게 = 이소 수↑, 대신 개체별 컨디션↓.
3. **먹이 질** (고품질 ↔ 양): 고단백 먹이는 구하기 어렵지만 성장↑.
4. **둥지 관리** (위생·방어 시간 배분, 만성성 종): 배설물 주머니 치우기 → 포식자 유인·기생충↓.
5. **이소·둥지 떠나는 시점** (일찍 ↔ 충분히): 일찍 = 둥지 포식 위험↓, 새끼 미숙. 늦게 = 반대.
6. **이소 후 돌봄 기간** (짧게 ↔ 길게): 길면 새끼 생존·학습↑, 부모 털갈이·2차 번식·이동 준비 지연.
7. **학습 기회** (안전 위주 ↔ 경험 위주): 다양한 먹이터 데려가기(채식↑), 포식자 모빙 노출(경계↑, 위험), 노래 듣기(과시↑), 이동 동행(항법·지역 지식, 가족 종).

조성성 종(꼬마물떼새, 두루미)은 항목이 바뀐다: 호위 거리, 먹이터 안내, 비·추위 때 품어 주기(체온 보호), 위장 지시(새끼가 엎드려 숨기).

### 7.4 독립 & 계승 화면 [초안]
새끼가 독립할 때 각 새끼의 카드가 나온다.
- 성별, 잠재력 등급(범위로 표시, 불확실성 있음), 은수저 지수, 학습 스탯, 성격 힌트, 문화 지식(가족 종)
- 선택: **[이 개체로 1년 더]** 또는 **[이 새끼로 계승]**
- 비교 정보: 현재 개체의 나이·노화 배율·짝 유대 / 새끼가 앞으로 겪을 고위험 구간(첫 겨울, 첫 이동, 미성숙 연수)

## 8. 종 설계 (첫 구현 4종) [확정: 4종 / 초안: 세부]

### 8.1 선정 이유
네 종이 생활사 스펙트럼(빠름 → 느림), 서식지(숲 / 하천 / 갯벌·섬 / 습지·농경지), 체류 형태(텃새 / 여름철새 / 여름철새 / 겨울철새), 육아 형태(둥지에서 키움 / 조성성 / 콜로니에서 게워 먹임 / 조성성 가족)를 고르게 나눈다.

### 8.3 게임 밸런스 — 총 번식 수 기준 동등 [확정 원칙 + 초안 수치]

원칙: 같은 실력이면 어떤 종을 골라도 **런당 총 번식 수의 기대값이 같다.** 종별 가중치는 없다. 종의 차이는 그 기대값에 도달하는 **경로와 분산**에 있다.

```
기대 총 번식 수 ≈ 평균 런 길이(년) × 번식 가능한 해의 비율 × 그해 기대 번식 성공 수
```

| | 박새 | 꼬마물떼새 | 저어새 | 두루미 |
|---|---|---|---|---|
| 1년 최대 번식 성공 | 2 (1차 + 2차) | 1 (실패 시 재산란으로 재도전) | 1 | 1 |
| 평균 런 길이(목표) | 약 4.5년 | 약 5.5년 | 약 7.5년 | 약 8.5년 |
| 계승 시 번식 공백 | 없음(다음 봄 번식) | 없음(다음 봄 번식) | 3~4번식기 | 2~3번식기 |
| 번식 가능한 해의 비율(평균 플레이어) | 약 1.0 | 약 1.0 | 약 0.8 | 약 0.85 |
| 그해 기대 번식 성공(평균 플레이어) | 약 0.9 (1차 약 55% + 2차) | 약 0.73 (재산란 포함) | 약 0.67 | 약 0.55 |
| **기대 총 번식 수(평균 플레이어)** | **약 4.0** | **약 4.0** | **약 4.0** | **약 4.0** |

- 위 수치는 생태 사실이 아니라 **설계 목표값**이며, 봇 시뮬레이션으로 맞춘다(13.3).
- 숙련 플레이 기준으로도 같아야 한다: 숙련 봇의 평균과 상위 10% 값이 종 간 ±10% 이내.
- 4종 모두 런 시작은 '첫 번식기를 앞둔 젊은 성조'(4.1).

**같은 기대값에 도달하는 방식의 차이 (플레이 성격)**

| | 박새 | 꼬마물떼새 | 저어새 | 두루미 |
|---|---|---|---|---|
| 점수가 쌓이는 방식 | 짧은 런, 1년에 최대 2 | 실패해도 같은 해에 재도전 | 계승 타이밍이 점수를 좌우 | 긴 런, 해마다 꾸준히 |
| 분산(운 비중) | 매우 큼 | 큼 | 중간 | 작음 |
| 런을 끝내는 주된 위험 | 겨울, 2차 번식 후 체력 고갈 | 이동, 장마철 | 이동, 계승 후 미성숙기 | 혹한, 이동, 계승 후 미성숙기 |
| 계승의 의미 | 거의 매년 고민(공백 없음, 대신 첫 겨울 위험) | 2~3년마다 | 몇 번 안 되는 큰 결단(공백 3~4번식기) | 드문 큰 결단(공백 2~3번식기, 첫 겨울은 가족 보호) |
| 배우기 | 쉬움 | 보통 | 어려움 | 어려움 |
| 상한을 막는 장치 | 2차 번식의 번식 비용, 빠른 노화 | 홍수 연타, 이동 위험 | 월동지 질병, 계승 공백 | 1년 최대 1, 계승 공백 |

**새끼 수의 역할**
- 한배 새끼 수는 점수에 직접 더해지지 않는다. 대신
  1. 새끼가 많을수록 '1마리 이상 독립'할 확률이 오른다(위험 분산).
  2. 후계 후보가 많아져 좋은 개체를 고를 폭이 넓어진다.
  3. 많이 낳고 키울수록 부모의 번식 비용(에너지·깃털·생존)이 커진다.
- 그래서 **산란수 결정**이 "많이 낳아 성공 확률과 후계 폭을 키울지, 적게 낳아 내 몸을 지켜 런을 늘릴지"를 고르는 핵심 전략이 된다(생활사 이론의 번식 비용 트레이드오프). 시뮬레이션에서 극단 전략(최소 산란, 최대 산란)이 지배 전략이 되지 않는지 확인한다.

### 8.4 박새 (Parus minor) — 입문, 빠른 생애, 변동성 최대

- 정체성: 숲의 작은 전략가. 많이 낳고 빨리 바뀌는 계보.
- 생태 요약: 흔한 텃새. 번식기 4~7월, 한배 보통 7~10개, 연 2회 번식 가능. 산란 시작은 지역의 봄 기온에 따라 3월 말~4월 말로 달라지며, 새끼 먹이가 되는 곤충이 가장 많은 때에 맞춘다. 번식기 외에는 쇠박새·진박새·동고비 등과 혼성군을 이룬다.
- 연간 일정
  - 1~2월: 겨울 혼성군, 체온·에너지 관리
  - 3월: 영역 노래, 짝 맺기
  - 4월: 둥지(나무구멍), 산란 시기 결정 ← 애벌레 피크 예측
  - 4~5월: 포란, 육추
  - 6월: 이소, 이소 후 돌봄 → **독립: 계승 결정 #1**
  - 6~7월: (선택) 2차 번식 → **독립: 계승 결정 #2**
  - 7~9월: 털갈이
  - 9~11월: 가을 혼성군, 분산
  - 12월: 겨울
- 짝·육아: 암컷이 둥지·포란 전담, 수컷은 포란 중 암컷에게 먹이 공급. 육추는 암수가 번갈아. 박새 부모의 조건부 협력(번갈아 급이)이 짝 지시 상호성 모델의 근거.
- 적성(초안): 채식 A, 경계 A, 사회 A, 과시 B, 비행 C, 체력 D, 항법 없음
- 고유 메카닉
  - **경보음 해석**: 박새는 뱀에는 'jar', 까마귀·담비 등 다른 포식자에는 'chicka'라는 서로 다른 경보음을 낸다. 뱀 경보를 들은 새끼는 둥지 구멍 밖으로 뛰쳐나간다. → 둥지 단계에서 '탈출 / 웅크리기' 선택.
  - **혼성군 동료 카드**: 쇠박새, 진박새, 오목눈이, 동고비 등이 각자 보너스(서포트 카드 역할). 다른 종도 박새의 뱀 경보음에 반응한다는 연구 → 경계 공유.
  - **애벌레 피크 맞추기**: 산란 시기 결정이 핵심 도박. 이상 기온 해에는 피크가 엇갈림.
  - **나무구멍 경쟁**: 구멍 수는 노령목·딱따구리에 달림. 다른 구멍 둥지 종과 경쟁.
  - **2차 번식 결정**: 새끼 수↑ vs 털갈이 지연·생존↓.
- 위험 요소
  - 자연: 둥지 포식(누룩뱀 등 뱀, 족제비, 담비, 어치·큰부리까마귀 등) [포식자 목록 검수 필요], 성조 포식(새매, 참매, 밤의 올빼미류), 한파·폭설, 장마 저온기 먹이 감소, 둥지 기생충, 부상
  - 드문 인공: 숲 벌채
- 점수 구조: 1년 최대 2번식. 런이 짧아(목표 약 4.5년) 한 해 한 해가 큰 승부. 2차 번식은 점수를 1 더 얻을 기회지만, 털갈이 지연과 체력 고갈로 그해 겨울 게임 오버 위험을 키운다. 계승해도 다음 봄에 바로 번식하므로 공백이 없다.
- 플레이 감각: 규칙이 단순하고 한 해가 빠르게 흐른다. 매 번식이 승부, 계승이 잦아 '진화'를 빨리 체감.

### 8.5 꼬마물떼새 (Charadrius dubius) — 중간, 홍수와 싸우는 지상 둥지

- 정체성: 자갈밭 위의 위장술사. 무너지면 다시 짓는 끈기.
- 생태 요약: 흔한 여름철새. 3월 중순 도래, 9월 하순까지 관찰. 하천 자갈밭·모래밭에 오목한 둥지, 알 4개, 포란 24~28일 암수 교대. 수컷이 마련한 둥지를 암컷이 받아들여야 짝이 성립. 햇볕이 뜨거우면 물을 적셔 알을 식혀 주기도 한다. 아프리카·인도·동남아에서 월동.
- 연간 일정
  - 3월 중순: 도래, 둥지 자리 경쟁
  - 4월: 짝 성립(둥지 수락), 산란
  - 4~5월: 포란 ← 장마 전에 끝내는 것이 관건
  - 5~6월: 부화, 새끼 호위(조성성) → 비행 → **독립: 계승 결정**
  - 6~7월: 실패 시 재산란(대체 산란) 기회, 장마
  - 8~9월: 털갈이·지방 축적, 남하 이동
  - 10~2월: 월동지
  - 3월: 북상
- 짝·육아: 포란 교대 리듬, 다친 척 유인 분담, 새끼는 스스로 먹으므로 호위·체온 보호·위장 지시가 육아의 핵심.
- 적성(초안): 경계 A, 비행 B, 채식 B, 항법 B, 체력 C, 과시 C, 사회 C
- 고유 메카닉
  - **다친 척 유인**: 포식자가 둥지에 다가오면 날개를 다친 척하며 끌어냄. 타이밍 미니게임. 너무 가까이 끌면 본인이 위험.
  - **알 식히기**: 폭염 단계에서 물을 적셔 알 온도 관리. 실패 시 부화율↓.
  - **홍수의 양면성**: 장마·홍수는 둥지를 쓸어가지만, 새 자갈밭을 만들어 다음 해 번식지를 늘린다. 홍수가 없는 해가 이어지면 풀이 자라 번식지가 사라진다(천이).
  - **위장**: 알과 새끼가 자갈과 닮음 → '가만히 있기'가 강력한 선택지.
- 위험 요소
  - 자연: 장마·홍수, 폭염, 지상 포식자(너구리, 족제비, 삵 등)와 까마귀류·맹금류 [목록 검수 필요], 이동 중 기상, 월동지 가뭄
  - 드문 인공: 하천 정비·준설(모래톱·자갈밭 소실)
- 점수 구조: 1년 최대 1번식이지만 실패해도 재산란으로 같은 해에 재도전할 수 있어 시즌 성공률이 높고 안정적. 런은 중간(목표 약 5.5년). 계승해도 다음 봄에 바로 번식.
- 플레이 감각: 한 번 무너져도 다시 지을 수 있는 회복형. 장마 일정과의 레이스.

### 8.6 저어새 (Platalea minor) — 중상, 갯벌과 콜로니의 전략가

- 정체성: 한국 서해가 고향인 멸종위기종. 조석과 이웃을 읽는 새.
- 생태 요약: 전 세계 번식 개체군의 90% 이상이 한국 서해안 무인도에서 번식(번식기 4~7월). 2026년 국내 번식쌍 약 3,300쌍, 남해안 첫 번식 확인. 2026년 국제 동시 센서스 세계 7,746마리. 한배 2~3개, 포란 약 26일, 육추 약 40일. 첫 번식 약 5세(암컷은 3세에 성성숙 보고), 20년 이상 생존 기록, 성조 평균 연생존율 약 0.8. 월동지는 대만(타이난 최대), 홍콩 딥베이, 일본 규슈~류큐, 마카오, 베트남 북부, 일부 제주. 가을에 부모가 새끼와 가족 단위로 대만에 간다는 관찰이 있고, 어린 개체는 월동지에 더 오래 머문다. 2002~2003년 대만 월동지에서 보툴리즘으로 73마리(당시 세계 개체수의 약 7%) 폐사. 박명 시간대에 갯벌에서 먹이를 찾는 경향.
- 연간 일정
  - 3~4월: 서해 무인도 번식지 도래, 콜로니 자리·짝
  - 4~5월: 산란, 포란
  - 5~7월: 육추(게워서 먹임) ← 갯벌 vs 담수 먹이터 선택
  - 7~8월: 이소, 갯벌에서 가족 채식
  - 10~11월: 가족 남하
  - 11~3월: 월동 → **월동 중 가족 해산: 계승 결정**
  - 3월: 북상
- 미성숙기: 계승한 새끼는 몇 년간 번식하지 않고 월동지에 남거나 늦게 돌아오는 해가 있다 → 계승 비용이 큼.
- 짝·육아: 콜로니 이웃 관계, 둥지 재료 분담, 게워 먹이는 급이 리듬.
- 적성(초안): 채식 A(갯벌), 사회 A(콜로니), 비행 B, 경계 B, 체력 B, 항법 B, 과시 C
- 고유 메카닉
  - **조석표**: 갯벌 채식은 썰물에만. 만조 때 쉴 곳의 안전도가 회복량 결정. 박명·야간 채식 선택지(부리를 휘저어 촉감으로 먹이를 찾음).
  - **콜로니 정치**: 중앙 = 안전하지만 자리 경쟁, 가장자리 = 쉽지만 위험. 이웃의 둥지 재료 도둑질.
  - **육추기 먹이터 선택**: 번식섬 가까이 갯벌이 있어도 새끼 먹이로 담수 습지 먹이가 많이 쓰인다는 연구 → 가까운 갯벌 vs 먼 담수(논·저수지) 선택.
  - **밀도와 질병**: 월동지 밀집이 클수록 보툴리즘 위험↑.
- 위험 요소
  - 자연: 번식섬 만조·폭풍해일로 둥지 침수, 갈매기류의 알·새끼 포식 [검수 필요], 이동 중 태풍, 월동지 보툴리즘, 한파
  - 드문 인공: 갯벌 매립(새만금 모델: 9장, 출처는 16장), 월동지 개발
- 점수 구조: 1년 최대 1번식. 계승하면 3~4번식기를 쉬어야 하므로 **언제 계승하느냐**가 총 번식 수를 좌우한다. 런은 긴 편(목표 약 7.5년).
- 플레이 감각: 시간표(물때)와 사회(이웃)를 동시에 관리하는 퍼즐형. 성조는 비교적 안정, 번식은 까다로움.

### 8.7 두루미 (Grus japonensis) — 상, 평생 짝과 가족의 장기전

- 정체성: 철원 평야의 겨울 손님. 오래 살고 적게 낳고, 가족이 함께 이동한다.
- 생태 요약: 매년 10월 말~3월 중순 한국 월동(철원이 최대 월동지, 2025년 11월 조사에서 철원 두루미 1,567마리). 번식은 러시아 우수리·중국 동북 습지. 평생 짝, 춤으로 유대 강화. 알 2개, 암수 교대 포란 29~34일. 새끼는 부화 직후 걸어 다니고 약 70일 후 날며, 약 9개월간 부모와 함께 지내다 늦겨울(대개 3월)에 떨어진다. 번식 성숙 3~4세. 부화 후 암컷이 주로 먹이고 수컷이 지킨다는 기록. 한국 겨울 먹이는 낙곡, 하천의 저서무척추동물, 미꾸라지 등.
- 연간 일정
  - 10~11월: 가족 남하, 한국 도착
  - 11~2월: 철원 등 월동(낙곡, 얼지 않는 물가 잠자리), 가족 서열
  - 2~3월: **가족 해산: 계승 결정(한국에서 일어남)**, 북상
  - 4월: 번식지 영역(작년 그 자리), 산란 2알
  - 5~6월: 포란(밤엔 암컷), 부화
  - 6~8월: 새끼 호위·급이(형제 경쟁) → 비행
  - 9~10월: 가족 이동 준비 → 남하
- 짝·육아: 짝 유대가 모든 협력의 기반. 오래된 짝일수록 지시 수락률이 높고 성격을 다 안다.
- 적성(초안): 체력 A, 경계 A, 과시 A(춤), 사회 A(가족), 항법 A(학습), 비행 B, 채식 C
- 고유 메카닉
  - **춤·이중창으로 유대 관리**: 유대가 높으면 육아 협력↑. 번식 실패가 반복되면 드물게 이별.
  - **가족 이동과 문화 계승**: 새끼가 부모를 따라 경로·월동지·잠자리를 배움 → 계승 시 지역 지식 일부 승계.
  - **형제 경쟁**: 알 2개 중 둘 다 키우기 어려움. 먹이 배분 방침이 결정적.
  - **가족 서열**: 새끼를 데리고 다니는 가족이 먹이터 다툼에서 유리 [검수 필요: 기러기류에선 잘 알려짐, 두루미 적용 확인].
  - **월동지 풍흉**: 추수 상태가 그해 먹이를 결정. (실제로 2025년 가을 폭우로 추수가 늦어 낙곡에서 싹이 트며 먹이가 줄자 두루미들이 예년보다 일찍 남쪽으로 떠났다는 보도 → 이벤트 근거)
- 위험 요소
  - 자연: 혹한·결빙, 이동 중 악천후, 번식지 새끼 포식(여우·너구리·맹금류 등) [검수 필요], 번식지 봄 가뭄·습지 화재 [검수 필요], 월동지 먹이 부족
  - 드문 인공: 월동지 농경지 변화(민통선 북상과 개발로 이용하던 농경지가 줄어든다는 지적)
- 점수 구조: 1년 최대 1번식. 성조가 안정적이라 런이 가장 길다(목표 약 8.5년). 알이 2개뿐이라 한 번식의 성공이 형제 경쟁·호위에 크게 달린다. 계승 공백 2~3번식기.
- 플레이 감각: 한 해 고점은 낮지만 무너지지 않는 장기전. 계승은 드물고 무겁다.

## 9. 환경 변화 시스템 [확정 방향 + 초안]

세계 지도(노드)는 세대를 넘어 변한다. 대부분 자연 변화, 사람의 개발은 몇 세대에 한 번의 큰 사건.

**자연 변화**
- 숲의 천이: 덤불이 오랜 시간 숲으로 → 덤불 종 터전↓, 숲 종↑
- 하천 범람: 둥지 유실 + 새 자갈밭 생성(꼬마물떼새)
- 산불: 숲을 초기 상태로
- 해거리: 도토리·씨앗 풍흉
- 혹한의 해, 이상 기후의 해, 곤충 대발생
- 월동지 작황(두루미)

**인공 변화 (드물게, 큰 서사)**
- **갯벌 매립**: 새만금이 모델. 방조제 완공 후 2006~2008년 북상 이동기에 13만 7천 마리의 물새가 사라졌고 그중 붉은어깨도요가 약 9만 마리(세계 개체군의 4분의 1 가까이), 이들이 국내 다른 갯벌로 옮겨간 증거는 없었다. → 게임에서도 **기착지·먹이터가 사라지면 대체지가 자동으로 생기지 않는다.** 그 장소를 대대로 배운 가문일수록 타격이 큼(문화 계승의 양면성).
- 논 개발(기러기·두루미 취식지 소실), 하천 정비, 숲 벌채
- **조짐**: 먹이 생물이 몇 해에 걸쳐 줄어드는 자연 단서로 미리 감지 가능.

## 11. 점수와 리더보드 [확정 + 초안]

### 11.1 최종 점수 = 총 번식 수 [확정]
- **총 번식 수**: 한 런 동안 플레이어가 조작한 개체가 **새끼를 1마리 이상 독립까지 키워 낸 번식의 횟수**.
- 집계 규칙 [초안]
  - 한 둥지(한배) = 1번식. 그 둥지에서 1마리 이상 독립하면 +1. 새끼가 몇 마리든 +1.
  - 박새의 2차 번식은 별도의 번식으로 +1.
  - 실패 후 재산란이 성공하면 그 둥지로 +1. (꼬마물떼새는 한 해 최대 1회 성공 [검수 필요: 2회 번식 여부])
  - 조작 중인 개체의 번식만 센다. 계승으로 떠난 부모, 형제자매의 번식은 세지 않는다.
  - 독립 순간 즉시 확정되므로, 게임 오버 시 정산할 미결 점수가 없다.
- 종별 가중치·보너스 없음. 생애 칭호는 기록일 뿐 점수에 더하지 않는다.

### 11.2 왜 '새끼 수'가 아니라 '번식 성공 횟수'인가
- 한배 알 수가 종마다 크게 다르다(박새 보통 7~10개에 1년 최대 2회, 두루미 2개). 새끼 수를 그대로 세면 같은 연수 안에서 빠른 종이 압도적으로 유리하다. 이를 맞추려면 종별 가중치를 쓰거나, 박새 새끼 생존율을 비현실적으로 낮추거나, 두루미 런을 수십 년으로 늘려야 하는데, 모두 다른 확정 사항(가중치 없음, 생태 정확성, 평균 10년 이내 게임 오버)과 충돌한다.
- '번식 개체로 자란 자손 수'는 평생 기준으로는 종 간 비슷하지만(개체군 유지 조건), 연 단위로는 빠른 종이 훨씬 빨리 쌓는다 → 같은 문제.
- '번식 성공 횟수'는 모든 종이 1년에 0~1회(박새만 0~2회)라 단위가 같고, 생태를 비틀지 않고도 성공률·런 길이·계승 공백으로 기대값을 맞출 수 있다.

### 11.3 부가 기록 (점수 아님)
- 독립시킨 새끼 수, 최장 생존 연수, 최장 계보(세대 수), 생애 칭호, 도감 완성도
- 종별 기록 화면에서만 비교한다. 종 간 비교는 총 번식 수만.

### 11.4 리더보드
- **통합 리더보드 하나로 모든 종을 그대로 비교**(가중치 없음). 종별 필터 제공.
- 동점이면 먼저 달성한 기록이 위.
- **주간 시드 챌린지**: 같은 종·같은 날씨·사건 시드로 친구들이 겨룸 → 운을 통제한 전략 대결.
- 자유 모드: 완전 랜덤(운 포함).
- 과금 없음: 종·도감·칭호는 모두 플레이로 해금.
- 밸런스 감시: 실제 플레이 기록에서 종별 평균 총 번식 수가 ±10% 넘게 벌어지면 성공률·위험 파라미터를 조정한다.

## 12. 생태 오류 체크리스트

다음은 넣지 않는다.
- 부모가 훈련한 스탯이 그대로 유전 (라마르크식)
- 레벨업 = 몸집 성장 (새는 성체 크기에 빨리 도달하고 더 자라지 않음)
- 한국에서 번식하지 않는 종이 한국에서 부화 (예: 두루미의 번식지는 러시아·중국)
- 원앙 = 평생 부부 (실제로는 해마다 짝을 새로 고르고, 수컷은 육아에 참여하지 않음)
- 땅에 있는 이소 직후 새끼 = 버려진 새끼
- 포식자 = 악당 보스 (포식자도 새끼를 먹여야 하는 생태계 구성원)
- 대부분의 산새가 독립 후에도 부모와 함께 지냄 (가족 단위 종은 예외)
- 박새 수컷의 포란 (박새는 암컷이 포란)

## 13. 개발 계획 [초안]

### 13.1 기술 [확정 방향]
- **모바일 웹 + PWA**. 링크 하나로 공유, 홈 화면 설치 가능.
- 구체적인 스택은 엔진 부서가 ADR-001로 결정(`docs/adr/0001-tech-stack.md`). 호스팅·리더보드 백엔드는 클라이언트·배포 부서가 ADR-002로 결정(무료 등급).
- 게임 로직은 UI와 분리(순수 함수 + 시드 고정 난수) → 같은 엔진으로 봇 시뮬레이션과 주간 시드를 돌린다.
- 모듈 경계·데이터 형식·엔진 API: `docs/studio/03-contracts.md`.

### 13.2 데이터 주도 설계
- 코드 수정 없이 콘텐츠를 늘릴 수 있도록 데이터 파일로 관리한다. **생태 사실(생태·콘텐츠)과 조정 가능한 수치(게임디자인)를 다른 파일로 분리**한다.
  - `data/species/*.ecology.json`: 종의 생태 사실 (콘텐츠)
  - `data/balance/`: 공식 계수, 종별 밸런스·적성·노화, 효과 등급표, 목표치 (디자인)
  - `data/events/`: 이벤트 — 글·조건·생태 근거, 효과는 등급으로 참조 (콘텐츠, 디자인 리뷰)
  - `data/nodes/`, `data/predators/`, `data/codex/`: 지도 장소, 포식자, 도감 (콘텐츠)
- 형식 예시: `docs/studio/03-contracts.md` 4장.

### 13.3 밸런스 시뮬레이터 (출시급 게임성의 핵심)
- 그래픽 없이 봇 3종(무작위 / 평균 플레이어 / 숙련)으로 수천 런 자동 실행.
- 확인 지표
  - **종별 기대 총 번식 수 균등**: 평균 봇 약 4.0, 숙련 봇은 평균과 상위 10% 모두 종 간 ±10% 이내
  - 종별 평균 런 길이(8.3 목표, 모두 10년 이하)
  - 번식 가능한 해의 비율, 계승 주기
  - 산란수 전략별 결과(극단 전략이 지배하지 않는지)
  - 이벤트별 사망 기여도

### 13.4 단계 (마일스톤)
상세는 `docs/studio/02-roadmap.md`.
- M0 착수: 기술 스택, 저장소·CI, 명세 v0, 화풍 결정
- M1 박새 수직 슬라이스: 꾸밈 없는 UI로 박새 여러 해 플레이
- M2 박새 밸런스: 평균 봇 기대 총 번식 수 ≈4.0, 평균 런 ≈4.5년
- M3 알파: 박새 에셋·화면 마감, 친구 알파
- M4 두루미+공정성: 박새·두루미 ±10%
- M5 4종 완성: 꼬마물떼새·저어새, 환경 변화, 칭호
- M6 베타: 리더보드, 주간 시드, 완성도
- M7 출시·운영: 1.0 공개
- 이후: 후속 종(때까치, 큰뒷부리도요, 오목눈이, 뻐꾸기, 가창오리 등)

## 14. 참고 게임 분석 요약

- **우마무스메**: 3년 72턴(한 달 2턴), 단계별 목표를 달성해야 진행, 체력이 낮을수록 트레이닝 실패율↑, 다음 육성에 능력치·스킬 힌트 계승(인자). 숙련자도 한 판 20~40분.
- **실황파워프로 석세스**: 우마무스메가 벤치마킹한 원형. 한 판 = 한 번의 육성.
- **스포츠 커리어 모드(FC, New Star Soccer)**: 선수 생성 → 경기 평가로 성장 → 은퇴와 통산 기록.
- **프린세스 메이커**: 기간별 스케줄·방침으로 스탯 육성, 스탯 조합에 따른 멀티 엔딩.
- **Shelter 2**: 어미 스라소니로 새끼를 키우고, 살아남은 새끼 중 하나로 다음 세대를 이어감. 새끼들이 두 번째 가을에 떠나 다시 만나지 못함. 새끼가 모두 죽으면 가문 종료.
- **BitLife / Reigns**: 짧은 이벤트 카드, 죽으면 생애 요약과 후계.
- **Duck Life**: 미니게임 훈련으로 오리 능력치 상승.
- **Oregon Trail**: 자원 관리하며 긴 여정 — 철새 이동 파트 참고.

## 15. 미결 사항 / 다음 작업

미결 사항
1. 꼬마물떼새의 한 해 2회 번식 성공 허용 여부 [검수 필요] — 생태·콘텐츠 검수 후 게임디자인, M5
2. 계승으로 떠난 부모의 이후 번식을 기록에 남길지(점수에는 넣지 않음) — 게임디자인, M1
3. (게임디자인, M4) 미성숙기(저어새·두루미 계승 직후)의 플레이 내용: 총 번식 수가 0인 해를 플레이할 동기 설계(예: 짝 탐색·영역 확보·지역 지식이 첫 번식 성공률을 올림), 시간 압축 여부
4. 성별 선택: 첫 개체는 플레이어가 성별 선택? 이후는 계승 새끼의 성별로 결정 — 게임디자인, M1
5. 지도 범위와 노드 수(종별 번식지·월동지·기착지 포함) — 게임디자인·생태·콘텐츠, 박새 M1 / 두루미 M4 / 나머지 M5
6. 아트 스타일(화풍) — M0에 아트·UX 시안 → 대표 선택. UI 레이아웃(세로 한 손) — 아트·UX
7. [검수 필요] 표시 항목들의 생태 검수 — 생태·콘텐츠, 필요 시 동아리 전문가 검수
8. 게임 정식 이름·로고 — M3, 아트·UX 시안 → 대표
