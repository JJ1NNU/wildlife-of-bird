# ADR 0002: 호스팅 · 리더보드 백엔드

- 상태: 채택
- 날짜: 2026-10-03
- 결정 부서: client
- 리뷰: engine (`docs/adr/**`)

## 맥락

M0 관문 조건 하나가 "대표 폰에서 열리는 미리보기 주소"다(#16, #17). 조건:

- **무료 등급만**(D-007). 유료 전환은 대표 승인(L3)
- 웹(모바일 세로) + PWA, 친구들에게 **링크로 공유**(D-008)
- `client.md` 3장의 배포 경로: **PR 미리보기 · main → 스테이징 · 릴리스 태그 → 프로덕션**
- 리더보드(M6)는 **닉네임만** 받는다. 이메일 등 개인정보를 모으지 않는다(01-collaboration 12장)
- 리플레이 검증(P1, M6): 제출된 기록을 서버에서 엔진으로 다시 돌려 볼 수 있으면 좋다
- **저장소는 비공개**(`JJ1NNU/wildlife-of-bird`, private)
- 대표의 손이 가장 귀하다(R-002): 만들 계정과 비밀값이 적을수록 좋다
- 빌드 산출물은 `apps/web`의 Vite 정적 파일뿐이다(ADR-001). 서버 렌더링 없음

## 선택지

### 정적 호스팅

| 선택지 | 무료 한도 | PR 미리보기 | 설정 난이도 | 비고 |
|---|---|---|---|---|
| GitHub Pages | 대역폭 100GB/월(소프트) | 없음(직접 만들어야 함) | 계정 추가 없음 | **비공개 저장소는 유료 요금제에서만 가능 → 탈락** |
| **Cloudflare Pages** | 정적 요청·대역폭 **무제한**, 미리보기 **무제한**, 빌드 500회/월, 파일 20,000개·파일당 25MiB | 있음 — 브랜치마다 고정 주소(`<브랜치>.<프로젝트>.pages.dev`) | 계정 1개 + API 토큰 1개 | 서울 엣지. 리더보드까지 같은 계정에서 해결(아래) |
| Netlify | 크레딧제(월 300) — 배포마다 크레딧 소모 | 있음 | 계정 + GitHub 앱 연결 | PR이 잦으면 한도가 걱정된다 |
| Vercel (Hobby) | 대역폭 100GB/월 | 있음 | 계정 + GitHub 앱 연결 | 비상업 한정. 백엔드는 따로 골라야 한다 |

### 리더보드 백엔드 (M6에 만든다 — 지금은 고르기만)

| 선택지 | 무료 한도 | 데이터 보호 | 설정 난이도 | 비고 |
|---|---|---|---|---|
| Supabase | DB 500MB, 프로젝트 2개 | 브라우저가 공개 키로 DB에 직접 쓴다 → 행 수준 보안(RLS)을 잘못 짜면 그대로 뚫린다 | 계정 1개 더 | **7일간 활동이 없으면 일시정지** — 친구 대상 소규모 게임에 불리 |
| Firebase (Spark) | Firestore 1GiB, 읽기 5만·쓰기 2만/일 | 보안 규칙으로만 검증. **서버 함수는 유료(Blaze) 요금제** → 리플레이 검증 불가 | 구글 계정 + 프로젝트 | |
| **Cloudflare D1 + Pages Functions** | D1 5GB, 행 읽기 500만·쓰기 10만/일 / 함수 호출 10만/일(호출당 CPU 10ms) | DB는 공개되지 않는다. 브라우저는 **우리 함수**만 부르고, 함수가 검증 후 기록 | **호스팅과 같은 계정 — 추가 가입 없음** | 2026-09부터 무료 한도를 넘으면 그날은 쿼리가 실패(과금 아님) |

## 결정

**호스팅과 리더보드를 모두 Cloudflare 한 계정에서 한다.**

- 호스팅: **Cloudflare Pages**, 프로젝트 이름 `wildlife-of-bird`
- 리더보드(M6): **Pages Functions + D1**. 설정은 `infra/`에 둔다. **지금은 만들지 않는다**(15장)
- 배포는 GitHub Actions(`.github/workflows/deploy.yml`)가 `apps/web`을 빌드해 **직접 업로드**한다
  (Cloudflare의 GitHub 앱 연결은 쓰지 않는다 — 빌드가 CI와 같은 Node·같은 명령으로 돈다)

### 배포 경로

| 언제 | Pages 브랜치 | 주소 |
|---|---|---|
| PR 열기·갱신 | PR의 브랜치 이름 | `https://<브랜치>.wildlife-of-bird.pages.dev` — PR 댓글로 알린다 |
| main에 머지 | `main` | `https://main.wildlife-of-bird.pages.dev` = **스테이징 (대표 폰 주소)** |
| 릴리스 태그 `v*` | `production` (프로젝트의 프로덕션 브랜치) | `https://wildlife-of-bird.pages.dev` = **프로덕션** |

- 브랜치 이름의 `/`와 대문자는 Cloudflare가 `-`·소문자로 바꾼다. 실제 주소는 배포 결과를 PR 댓글에 그대로 적는다.
- 다른 저장소에서 온 PR(포크)은 비밀값을 못 받으므로 미리보기를 건너뛴다(모든 부서가 같은 저장소 브랜치를 쓰므로 해당 없음).

### 비밀값

| 이름 | 어디에 | 무엇 |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | GitHub 저장소 Secrets | 권한: Account → Cloudflare Pages → Edit **하나만** |
| `CLOUDFLARE_ACCOUNT_ID` | GitHub 저장소 Secrets | 계정 ID(비밀은 아니지만 함께 둔다) |

- 저장소에는 형식만 `.env.example`에 둔다. 브라우저 코드에 들어가는 키는 **없다**
  (리더보드도 우리 함수를 부르므로 공개 키가 필요 없다).
- 계정 생성과 비밀값 등록은 대표의 `type:human` 이슈 하나로 요청한다(#60).

### 공개 범위

`*.pages.dev` 주소는 **아는 사람만 들어오는(unlisted) 공개 주소**다. 로그인 없이 열린다.
게임 빌드에는 개인정보가 없으므로 M0~베타에는 이것으로 충분하다고 본다. 친구 한정으로
막아야 한다면 Cloudflare Access(무료 50명)를 나중에 붙일 수 있다 — 공개 범위는 대표 결정(L3).

### 개인정보 (리더보드, M6)

- 받는 것: **닉네임, 점수(총 번식 수), 종, 시드, 게임 버전(`version.json`), 리플레이용 선택 기록**
- 받지 않는 것: 이메일, 로그인, 기기 식별자. 함수는 IP를 DB에 적지 않는다
- 닉네임은 길이 제한·금칙어 검사를 함수에서 한다(M6에 정한다)

### 첫 화면 로딩 목표

- **일반 4G(약 1.6Mbps·지연 150ms 가정)에서 첫 화면 3초 이내**
- 그러려면 첫 화면의 **JS+CSS 합계 gzip 200KB 이하**를 예산으로 둔다(React+ReactDOM ≈ 60KB, 엔진·데이터·화면에 140KB)
- 그림 에셋은 첫 화면 이후 필요한 것만 불러온다(M3). 측정은 M2·M6에 Lighthouse 모바일로 한다

## 결과

- **좋아지는 것**
  - 대표가 만들 계정이 **Cloudflare 하나**, 등록할 비밀값이 **둘**뿐이다. 리더보드(M6)에서 더 늘지 않는다
  - PR마다 고정 주소의 미리보기가 생겨 대표·QA가 폰으로 바로 본다
  - 정적 요청은 한도가 없어 친구가 늘어도 호스팅비가 생기지 않는다
  - 리더보드 검증이 서버(함수)에서 돌아 리플레이 검증(P1)으로 이어갈 수 있다
- **감수하는 것**
  - 함수 호출 10만/일·CPU 10ms/호출 한도. 리플레이 검증이 10ms를 넘으면 M6에 다시 정한다(ADR 개정)
  - D1은 SQLite 방언이다. 리더보드 정도의 표 하나에는 문제가 없다
  - Cloudflare에 묶인다. 정적 파일이므로 호스팅은 언제든 옮길 수 있고, 리더보드만 다시 짜면 된다
- **다른 부서가 해야 할 일**
  - 대표: Cloudflare 계정 · API 토큰 · GitHub Secrets 등록 (#60)
  - engine: 이 ADR 리뷰. 리더보드 리플레이 검증(M6)은 엔진을 함수 안에서 돌린다 — 엔진이 브라우저·Node 외에 Workers 런타임에서도 돈다는 전제(순수 함수라 문제없을 것)
  - pm: 스테이징 주소를 대시보드 "미리보기 주소"와 대표 보고에 넣는다(#17에서 `dept:pm` 이슈로 전달)
