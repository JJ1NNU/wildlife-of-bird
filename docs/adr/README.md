# 기술 결정 기록 (ADR)

> 관리: 엔진. 작성: 결정한 부서. 되돌리기 어렵거나 여러 부서에 영향을 주는 기술 결정을 남긴다.

- 파일 이름: `NNNN-짧은-제목.md` (예: `0001-tech-stack.md`)
- 형식: `0000-template.md`
- 결정이 바뀌면 기존 ADR을 지우지 않는다. 새 ADR을 쓰고 기존 ADR의 상태를 "대체됨 → NNNN"으로 바꾼다.

| 번호 | 제목 | 부서 | 상태 |
|---|---|---|---|
| 0001 | 기술 스택 | engine | 작성 예정 (M0 첫 근무) |
| 0002 | 호스팅·리더보드 백엔드 | client | 작성 예정 (M0) |
