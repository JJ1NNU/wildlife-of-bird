## 1. 화풍 — **결정 대기 `잠정(#13)`**

시안 세 개와 아트 추천(A 수채 도감)은 `style-options.md`. 대표 선택 후 이 장에 다음을 적는다: 화풍 설명 / 색 팔레트 / 프롬프트 공통 블록 / 금지 표현.

**결정 전에도 지켜지는 것** (세 시안 공통, `style-options.md` 0장):
- 화면은 항상 **[그림 레이어] + [평면 벡터 UI 레이어]** 두 겹. UI는 화풍과 무관하게 평면 벡터다.
- 사람·건물·도로는 그리지 않는다. 드문 인공 이벤트 전용 그림에서만(gdd 2장 7).

## 2. 구도 규칙

| 분류 | 규칙 |

| `bird` `pred` | **옆모습, 왼쪽을 향한다.** 단색 배경에 단독. 캔버스 안 몸길이 비율을 종끼리 고정(아래 표) → 크기 비교가 되고 합성이 쉽다. 발끝과 캔버스 아래 여백 8%. |

## 3. 글자·대비·터치 (화풍과 무관, 반드시)

- 글자 대비 **WCAG AA**: 본문 4.5:1, 18px 이상 굵은 글자 3:1. 그림 위의 글자는 반투명 판 또는 단색 띠 위에 올린다.
- 터치 영역 **44×44px 이상**. 인접 터치 영역 사이 간격 8px 이상.
- 세로 한 손 조작. **360×640 ~ 430×932에서 가로 스크롤이 없어야 한다.**
- 폰트는 **OFL 등 자유 사용 라이선스만**. 한글 글립이 있어야 한다. 구체 선정은 디자인 토큰(#15).
- 색만으로 정보를 전하지 않는다 — 위험·확률은 색 + 아이콘 + 숫자를 함께 쓴다(gdd 3장 원칙 5).

## 4. 파일·ID·용량 예산

- 에셋 ID와 경로 규칙: `docs/studio/03-contracts.md` 5장. 파일은 `assets/<분류>/<ID>.<확장자>`.
- 대표 투입함: `assets/inbox/batch-NN/<에셋ID>__<후보번호>.webp` — 긴 변 **1024px 이하** (`assets/inbox/README.md`).

| 분류 | 최종 형식 | 최종 긴 변 | 용량 상한 |
|---|---|---|---|
| `bird` `pred` | WebP (알파) | 768px | **150KB** |
| `bg` | WebP | 1024px | **250KB** |
| `scene` | WebP | 1024px | **200KB** |

상한을 넘으면 품질을 낮추기 전에 **크기를 줄인다.** 넘는 에셋은 `asset-list.md`에 사유를 적는다.

## 5. 후처리 — **잠정(#2: ADR-001 기술 스택 확정 전)**

**지금은 후처리 도구를 정하지 않는다.** M0~M2에 필요한 후처리가 없기 때문이다.

- 자리표시 실루엣·아이콘은 SVG로 **직접 만든다**(변환 불필요).
- 대표가 올리는 이미지는 **처음부터 긴 변 1024px 이하**로 저장해 받는다(`assets/inbox/README.md`). 받자마자 쓸 수 있다.
- 첫 실제 후처리가 필요한 시점은 **M3(박새 에셋 완성)** 이다. 그때 ADR-001로 정해진 저장소 도구 체인에 맞춰 도구를 고르고 `scripts/art/`에 스크립트로 고정한다(01-collaboration 15장: 필요해질 때 만든다).

검증한 것 (2026-10-03, 대표 PC):

| 도구 | 상태 |
|---|---|
| ImageMagick (`magick`) | **설치되어 있지 않음** — 쓰려면 설치가 필요하다 |
| Node.js | 있음 → ADR-001이 Node를 고르면 `sharp`(Apache-2.0)가 가장 가까운 선택지 |
| Chrome (headless) | 있음 → **SVG → PNG 렌더·검수에 쓸 수 있다**(와이어프레임 검수에 실제로 썼다) |

**배경 제거는 하지 않는다.** 도구를 늘리는 대신 **단색 배경으로 요청하고 그 배경을 화면 디자인이 그대로 살린다** — 카드 바탕색 = 그림 배경색. 알파가 꼭 필요한 자리(새가 배경 그림 위에 올라가는 메인 턴 화면)는 **단색 배경 한 가지로 통일**해 두고, M3에 그 한 색만 빼는 한 줄 처리로 끝낸다. 이것으로 안 되는 화풍(시안 C)이면 화풍 선택 시점에 다시 판단한다.

- **의존성을 저장소에 추가할 때는 잠금 파일 변경을 포함해 `review:engine`** (01-collaboration 8장).
- 도구 설치가 필요해지면 `type:human` 이슈로 대표에게 요청한다.

`asset-list.md`에 에셋마다 적는다: **도구·모델 이름 / 생성 날짜 / 프롬프트 파일(`docs/art/prompts/`) / 배치 번호 / 콘텐츠 생태 검토 통과 여부(`bird` `pred` `scene`)**.

## 7. 금지

- 프롬프트에 **실존 작가 이름**을 쓰지 않는다. 사진이나 특정 그림을 따라 그리게 하지 않는다.
- 콘텐츠의 생태 검토를 통과하지 않은 새·포식자 그림을 **최종 에셋으로 쓰지 않는다**(자리표시·화풍 테스트는 예외).
- gdd 12장 생태 오류 체크리스트를 그림으로 저지르지 않는다 — 특히 **레벨업=몸집 성장**(새는 성체 크기에서 더 자라지 않는다. 성장은 깃·자세·행동으로 표현한다), **포식자=악당**(포식자도 새끼를 먹이는 생태계 구성원으로 그린다. 과장된 송곳니·붉은 눈 금지).
