# UI 키트 — 컴포넌트 규칙

> 소유: 아트·UX. 바꾸려면 `review:art` PR. 값은 모두 `packages/tokens/src/tokens.css`(`--wb-*`)를 가리킨다 — 여기에 숫자를 새로 정하지 않는다.
> 상위 규칙: `packages/tokens/README.md`(색·대비) · `docs/art/style-guide.md` 3장(글자·터치) · 배치: `docs/ux/wireframes/mid/`.
> 범위: **지금 `apps/web`에 있는 컴포넌트만**(#396, 01-collaboration 15장). 새 컴포넌트는 화면에 들어올 때 이 문서에 한 줄씩 더한다.
> 클래스 이름은 `apps/web/src/style.css` 기준(2026-10-09). M3 아트 스타일 적용 때 이 규칙을 지키는 한 생김새는 바뀔 수 있다.

## 0. 모든 컴포넌트 공통

| 무엇 | 규칙 |
|---|---|
| 터치 | 누를 수 있는 것은 가로·세로 `--wb-touch-min`(44px) 이상, 서로 `--wb-space-2`(8px) 이상 떨어짐. 예외는 아래 표에 적힌 것만 |
| 모서리 | 카드·시트·장면 띠 `--wb-radius-l` · 버튼·선택 카드·칸 `--wb-radius-m` |
| 여백 | 화면 좌우 `--wb-space-4`. 목록 사이 `--wb-space-2` |
| 상태 표시 | 선택됨 = **2px `sage-strong` 테두리 + `paper` 바탕** · 못 누름 = **점선 테두리 + `ink-muted` 글자** · 켜짐(세그먼트) = `slate-strong` 바탕 + `on-strong` 글자. 색만 바꾸지 않고 테두리 모양·굵기도 바꾼다 |
| 숫자 | 확률·에너지·수치는 `tabular-nums`(body에 이미 걸림) |
| 위험 | 색 + 아이콘 + 숫자 + 낱말(2장 위험 표시). 색 하나로 전하지 않는다 |

### 3.1 패 카드 v2 (#611 — #557 v1 대체)

**작은 카드, 3열 격자, 가진 것만.** 배치·높이 예산은 `docs/ux/screens.md` 6장, 와이어 `mid/07-one-screen.html`. 계절 방침·이벤트 선택지도 카드로 그리면 같은 규칙.

| 무엇 | 규칙 |
|---|---|
| 배치 | **3열 격자**, 사이 `space-2`. 가로 넘김(scroll-snap)·부채꼴 쓰지 않음. 넘치면 패 영역만 세로 스크롤(screens 6.2) |
| 크기 | 높이 52 고정 · 폭 = (화면 − 좌우 `space-4` − 사이 2개) ÷ 3(360 폭에서 ≈104). 바탕 `card`, 테두리 `line` 1px, `radius-m`, 그림자 없음 |
| 카드 안 | 1줄: **비용 배지**(원 18, `slate-strong` + `on-strong`, caption 굵게) + **이름**(small 굵게, 한 줄, 넘치면 말줄임). 2줄: **핵심 1줄** caption — 에너지 변화 · 위험%(기호 + 숫자). 행동 아이콘은 카드에 넣지 않는다(폭 104에 "비행 연습"이 안 들어감 — 아이콘은 칸에). 성장·위험 낱말·전체 효과는 정보 줄(G)로. 전체 정보는 `aria-label`에도 |
| 같은 카드 여러 장 | 한 장으로 묶고 오른쪽 위 모서리에 **×n 배지**(`paper` 바탕 + `slate-strong` 1px 테두리·글자, caption 굵게, 카드 밖으로 4~6px 걸침 — 폭을 쓰지 않게). 1장이면 배지 없음 |
| 다 쓴 카드 | **그리지 않는다.** 격자는 앞으로 당긴다. 칸에서 빼면 다시 나타남 |
| 못 씀(에너지 부족) `.short` | `paper` 바탕 + **점선** + 글 `ink-muted` + 비용 배지 `danger` + 2줄째가 이유 낱말(`에너지 부족`). 누르면 칸에 안 들어가고 정보 줄에 이유 한 줄 |
| ~~패에 없음 `.out`~~ | **없앰**(#611). 패에 없는 카드는 그리지 않는다 |
| ~~묶음 `.grp`~~ | **없앰.** 훈련은 패에 스탯별 카드로 들어오고(12-card-turn 2.1), 옮기기는 늘 있는 카드 → 아래 시트 |
| 늘 있는 카드(옮기기·채식 기본·쉬기) | 패와 다른 줄(F), **보조 버튼 모양**: `paper` 바탕 + `slate` 1.5px 테두리 + `slate-strong` 글자·아이콘, 높이 44. 장수 배지 없음 |
| 칸 `.cell`(v2) | 아이콘 16 + 그 칸 뒤 예상 에너지(caption 굵게). 다음 빈 칸 = 2px `sage-strong` **점선**, 누른 칸 `.sel` = 2px `sage-strong` 실선. 배고픔 구간 아래 칸의 숫자는 `ochre-strong` |
| 정보 줄 | 높이 44, 왼쪽 3px 선(`sage-strong`, 이유일 때 `danger`), caption 2줄. 위험은 띠 규칙(2장) 그대로 — 낱말 포함. 오른쪽 [빼기]는 보조 버튼 56×44 |
| 선택됨 들어 올림·그림자 | **없앰**(v1). 고른 카드는 칸으로 가므로 패에 선택 상태가 없다 |

그림자는 팁 카드(3.2)만 쓴다. 토큰이 없어 `color-mix(in srgb, var(--wb-color-ink) N%, transparent)`로 쓴다(#433 방식).

### 3.2 팁 카드 (06-tutorial 2장·5장)

**상태 바 바로 아래, 화면 흐름 안**의 한 장(#585 — 떠 있는 카드는 짝 후보 1 같은 버튼을 덮었다). 떠 있는 동안 `.zone`의 높이(550)는 그대로이고 아래 목록이 그만큼 줄어 스크롤된다. 뒤 화면을 막지 않으므로 **대상을 가리지 않는 것**이 모양의 목표다.

| 무엇 | 규칙 |
|---|---|
| 모양 | 바탕 `card`, 테두리 2px `ochre-strong`, `radius-l`, 그림자 `ink` 25%(화면 내용과 다른 안내라는 표시). 안쪽 여백 `space-3` `space-4`, 줄 사이 `space-1`. 폭 = 화면 − 좌우 `space-4`, 최대 480 |
| 글 | 제목 `small` 굵게 · 본문 `small` `ink`. 06의 "제목 1줄 + 본문 2줄"(T-00은 3줄)을 넘으면 문구를 줄인다(콘텐츠) — 카드를 키우지 않는다. 360 폭 T-00 높이 ≈145가 상한 |
| 가리키는 표시 | **화살표 없이 대상 테두리로.** 대상 요소에 `.tip-target` = `outline` 3px `ochre-strong` + `outline-offset` 2px(카드 테두리와 같은 색 = 짝이라는 표시). 레이아웃을 밀지 않게 `border`가 아니라 `outline`. 선택됨(2px `sage-strong`)·못 누름(점선)과 색·굵기가 겹치지 않는다. 화살표를 안 쓰는 이유: 패가 가로로 넘어가고(3.1) 화면이 세로로 흘러 화살표 끝이 대상에서 어긋난다 |
| 자리 | 늘 상태 바 바로 아래, `margin: space-2 space-4 0`, `flex: none`. 대상 자리에 따라 옮기지 않는다 — 흐름 안이라 아무것도 덮지 않고, 대상은 `.tip-target` 테두리로 찾는다. 대상이 여럿(패의 카드마다 에너지·위험, T-02·T-03)이면 첫 카드의 그 자리만 표시 |
| 닫기 | 카드 어디든 한 번 탭(카드 전체가 `button`, 44 이상). 닫기 버튼·✕를 따로 두지 않는다 |
| 막는 팁(T-30) | 계승 확인 전에 닫아야 하므로 겹침 시트(1장 `.zone.ov`)처럼 뒤를 `ink` 55%로 어둡게(대상은 어둡게 하지 않는다), 자리는 위와 같다. 다른 팁은 어둡게 하지 않는다 |
| 움직임 | 나타날 때 0.15초 흐림→선명 하나만. 움직임 줄이기 설정이면 없음 |

## 4. 지금 화면과 이 규칙의 차이 (클라이언트에 넘김)

M1 화면은 그대로 둔다(M1 관문 중). M3 아트 스타일 적용(클라이언트) 때 함께 고친다. 알파 시각 마감 리뷰(10/17, 미리보기 360×640)에서 다시 재 남은 것만 적는다 — 클라이언트 #599. `.tip`은 #588 #593 #594로 끝.

| 어디 | 지금 | 규칙 |
|---|---|---|
| `.step` | 높이 32px | 터치 44 — 칸 줄 머리 높이를 44로 늘리거나 버튼을 칸 줄 양옆으로 |
| `.cell .pl` | 글자 10px | 최소 `caption`(12px) — 칸이 좁으면 장소 이름을 줄여 쓰거나 표에만 |
| `.pol .seg button` | 선택지 이름이 `caption`(12px) | 고르는 데 꼭 필요한 글이라 `small`(14px) 이상 — 넘치면 두 줄 허용 |
| `.settings > summary` | 높이 24px | 터치 44 — `.codex-kind summary`와 같게 |
| `.link`("[지도]") | 폭 42px | 터치 44 — `min-width` |
| 몇몇 `padding`(`.opt` 3px 10px, `.status` 6px 등) | 토큰 밖 값 | 가능한 `--wb-space-*`로. 와이어프레임 높이 예산(550)을 맞추느라 쓴 값은 그대로 둬도 된다 |
